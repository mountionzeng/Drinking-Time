# 美术提示词库 · 维护说明

这套库把“什么样的画面最好看”保存成可以筛选、校准和调用的独立卡片。它只决定画面如何被表现，不改写用户说过的人物、关系、事件和情绪事实。

## 文件结构

```text
docs/style-library/
├─ WORD_BANK.md        # 给人看的筛选总表
├─ MANUAL.md           # 维护规则
├─ _TEMPLATE.yaml      # 新卡模板
└─ entries/*.yaml      # 程序读取的唯一真相源，一卡一文件
```

当前共有 24 张卡：12 张 `active`，12 张 `draft`。其中 8 张主风格和 1 张辅助效果具有语义自动选择元数据；三张由用户确认的核心卡是：

- `modernist-sanyu-seurat-wu`
- `dreamy-colored-pencil-minimal`
- `diffuse-motion-blur`

具体清单和筛选栏见 `WORD_BANK.md`。

## 最快维护方式

1. 在 `WORD_BANK.md` 中查看或比较现有卡。
2. 新内容复制 `_TEMPLATE.yaml` 到 `entries/<id>.yaml`。
3. 新卡保持 `status: draft`，先写视觉 DNA 和人工策展语境。
4. 出图校准，确认画面稳定、与现有卡拉得开。
5. 人工确认后才改成 `active`；需要自动选择时，再补经过审核的 `automatic_selection`。

`draft` 永远不会因为字段写得很完整就自动上线。删除卡片也必须由用户明确确认。

## 一张卡要回答的四件事

### 1. 它为什么好看

用 `one_liner` 和 `signature` 说清。`signature` 必须是低分辨率仍能看见的具体东西，例如“一根有书写感的轮廓线穿过大片留白”，不能只写“高级”“有感觉”。

### 2. 它具体怎么画

把词拆进稳定槽位：

- `style`：媒介、技法和造型语言。
- `palette`：少而明确的色板。
- `light`：光源、方向、软硬与时间感。
- `composition`：景别、主体位置、空间和留白。
- `material`：纸纹、笔触、颗粒、套色偏差等可见表面。
- `era_culture`：画面内部的时代文化，不是艺术家出处。
- `negative`：最容易翻车成什么。

### 3. 什么情况下适合

`selection_context` 是给人筛选和未来编译器使用的宽松语境：

- `moods`：用户当下表达出的心情。
- `life_experiences`：离家、毕业、照顾、失去、重启等具体经历。
- `explicit_age_or_stage`：只能来自用户明确提供的信息，而且永远不能单独触发画风。
- `eras`、`seasons`：用户明确说出的时间，或明确“当下”语境。
- `wardrobe`：人物确实出现时，随时代、季节和场景调整。
- `counter_signals`：出现什么情况时不应选择这张卡。

这些字段本身不会自动生效。只有经过审核并映射进 `automatic_selection.concepts` 的概念，才会被运行时选择器消费。

### 4. 什么情况下绝不能用

写进 `negative`、`selection_context.counter_signals` 和 `automatic_selection.forbidden_purposes`。产品标准图、事实复原、身份标准视图等用途默认不允许被情绪风格化覆盖。

## 艺术家和年代怎么使用

艺术家、电影和作品传统可以放在 `internal_references` 或 `automatic_selection.provenance`，用于内部策展和研究。发送给图片模型的 `style` 与 `provider_fragments` 只写可观察的画面语言，不要求复制特定艺术家的作品。

例如内部可以记录“常玉 / Georges Seurat / 吴冠中”，发给模型的是：

```text
书法性轮廓与概括色面；疏密点触组织空气感；大面积留白
```

用户明确要求某个年代时，可以研究那个年代的艺术语言和色调，再转换成可观察特征；不能只把艺术家姓名堆进 prompt。

## 情绪、年龄和生命体验的边界

- 当前表达优先，旧记录不能冒充今天的心情。
- 情绪必须能追溯到用户原话或当前故事卡证据；不做心理诊断。
- 年龄只接受用户明确提供或已授权的资料，并且只作弱辅助。
- 不按年龄、职业、五行给用户贴固定审美标签。旧卡里的 `affinity` 是历史字段，不参与新的语义自动选择。
- 同一句话有多种合理理解、证据不足或候选得分接近时，不自动套用。

## 时间、季节与服装

- 用户明确说“1990 年代”“小时候”“今年夏天”等时间时，画面时代、色调和服装保持一致。
- 用户明确说的是“当下”且人物出现时，运行时按上海时区当天日期使用当前季节的日常服装；不读取 GPS、IP，也不假装知道实时天气。
- 用户没有说明时间时，不为了好看擅自补一个强年代。
- 服装服务人物和场景，不抢走叙事主体，也不覆盖用户已经明确的穿着。
- 有人物参考图或故事板画面时，可见服装是更高优先级事实，季节规则不得替换它。

长期情绪画像仍用于每日回信与剧本共鸣，不进入美术自动选择。美术词库只消费本轮明确情绪；历史编辑注解可以继续作为审美偏好，但不能被当成用户此刻的心情。

## 自动选择的硬规则

1. 用户明确的风格、媒介、年代和画面要求优先。
2. 一次最多一张主风格和一张相容的辅助效果。
3. `active` 且具有完整 `automatic_selection` 的卡才可被自动选择。
4. 没有证据不随机补卡；低置信度和并列冲突都不选择。
5. 辅助效果不能改写主风格的色板、主体身份或内容事实。
6. provider adapter 不追加第二套风格规则。

## 上线前自检

- 画得出来吗，还是只有形容词？
- `signature` 在小图里也认得出来吗？
- 和现有卡在媒介、色温、年代、繁简、情绪温度上拉得开吗？
- 艺术家姓名是否只存在内部出处，而没有泄漏到 `provider_fragments`？
- 情绪和生命体验是否有真实证据？
- 年龄是否只是弱辅助？
- 时间、季节、服装是否有明确依据？
- `negative` 和反向信号是否写清了翻车边界？
- 新卡是否仍为 `draft`，等待人工确认？
