# 美术提示词库 · 策展与筛选总表

这份文件是给人看的总目录，不是新界面。程序真正读取的是
`docs/style-library/entries/*.yaml`；这里负责让你快速筛选、比较和提出新增内容。

## 怎么筛选

- `active`：已经可以被系统使用。
- `draft`：只在词库里保存，等待你筛选或出图校准，不会自动调用。
- `自动`：具有 `automatic_selection`，用户当下表达出现足够证据时才可能被语义选择器调用。
- `手动`：仍可作为明确指定的风格使用，但不会仅凭情绪自动套用。
- 淘汰条目不直接删除；你明确说“删除”后再移除，避免误伤既有能力。

你可以直接按下面的 id 回复，例如：

```text
保留：dreamy-colored-pencil-minimal、nabist-memory
待修改：modernist-sanyu-seurat-wu（希望更轻、更少点彩）
淘汰：vaporwave-neon
新增：夏日傍晚、刚离开校园、轻微不舍，薄水彩和长影子
```

## F. 自动选择的证据规则

1. 用户明确点名风格、媒介或画面特征时，优先尊重原话。
2. 当下情绪和生命体验可以帮助选择，但必须能从本轮表达或经授权的上下文找到证据。
3. 年龄只能来自用户明确提供的信息，而且只能作为弱证据；年龄本身不能触发画风。
4. 旧情绪不能被当成用户今天的状态，也不能形成永久人格标签。
5. 时间、年代、季节和服装只在用户明确表达或“当下”语境确实成立时加入；“当下”按上海时区当天日期判断季节，不读取位置。
6. 人物参考图或故事板里已经可见的服装优先，季节规则不得覆盖。
7. 没有足够证据、两张卡得分过近或用途不合适时，不自动套用任何卡。
8. 一次最多选择一张主风格和一张相容的辅助效果。

## G. 下一批值得补的空位

- 黑白硬纪实：高反差黑白、粗颗粒、直接闪光或街头抓拍。
- 明亮外光绘画：碎笔触、自然色温变化、空气与水面反光。
- 工笔重彩：细线、矿物色、东方精密装饰。
- 极简单线：纯线条、少量局部色、极大留白。
- 综合材料拼贴：撕纸边缘、旧票据、织物、手写痕迹但最终画面仍禁止可读文字。
- 像素低保真：受限色板、方块边缘、早期数码质感。
- 丝网版画：高饱和套色、重复图式、印刷错位。
- 黏土定格：手捏痕迹、微缩布景、柔和实体光。
