# 情绪与叙事驱动的联合美术配方

## Summary

在既有美术词库中协调色环关系、明暗块面、空间位置与艺术参照、媒介和笔触，形成服务当前故事的一套相容配方，而非独立规则堆叠。沿用聊天交互，保留用户指定与照片事实，不增加界面或每次生成的额外分析调用。

本文记录用户已确认的需求；不代表运行逻辑已实现，也不代表真实出图效果已验收。

---

## Problem Frame

用户希望生成图的美术语言更丰富，并指出不同情绪可能适合集中于单个色相，也可能适合互补色。只有颜色名称不能描述画面关系：相同的蓝与橙，以不同面积、浓度和位置呈现，可能产生截然不同的体验。

现有风格库可保存色板并产生色彩片段，参考图库可提取色彩关系标签；这些能力尚未形成统一的色环分布与面积、强度、位置选择规范。已有图库记录也不应因此被视为缺失或失效。

用户进一步指出不同艺术参照的用色方法不同。相同色相和亮度分布，如果颜色的位置、亮暗块面的组织或笔触尺度不同，也会形成不同画面；独立堆叠情绪、色卡和媒介要求可能产生矛盾或趋同。

---

## Requirements

**配色表达**

- R1. 分开描述具体颜色与颜色之间的关系。配色方案至少说明色相关系、主辅或点睛角色、相对面积、饱和度、明暗对比以及画面中的落点；无证据的细节允许保持开放，不伪造精度。
- R2. 首批支持下表五类关系，允许交叉标签与其他有依据的观察，不以分类清单限制参考图提取。角度只在选定色环中作为近似关系，不当作跨色彩模型的精确数值。

| 关系 | 色环上的概念分布 | 候选表达用途，非固定情绪映射 |
|---|---|---|
| 单色相 | 一个色相附近，通过明暗、饱和度变化形成层次 | 安静、沉浸、孤独、专注 |
| 邻近色 | 一段相邻色域 | 温柔、亲密、连贯、朦胧记忆 |
| 互补色 | 两个色域约相隔 180° | 矛盾、相遇、张力、希望突破 |
| 分裂互补 | 主色与其互补色两侧的色域 | 复杂、犹豫、变化与平衡 |
| 三角色 | 三个色域约相隔 120° | 活跃、玩心、生活的丰富感 |

- R3. 配色关系不规定均等面积或鲜艳程度。可以使用大面积低饱和主色、小面积辅色和少量点睛色；比例按内容决定，不将某个比例设为所有画面的模板。黑白灰等中性色可参与，单色相不等于所有像素同色。
- R4. 颜色的空间位置参与叙事，例如背景、人物、远处光点或物件之间的对照；不得为了实现色彩关系增添无关人物、物件或改变事件。

**选择与覆盖**

- R5. 仅以当前明确情绪、当前故事或镜头表达、用户美术要求作为选择依据。情绪是艺术候选线索，不是心理诊断；不以历史情绪画像或推断年龄触发配色。
- R6. 用户指定颜色、已确认配方及需要保留的参考画面事实优先于自动方案。自动补充仅发生在尚未指定且不冲突的维度；保留原提示词、锁定美术及作者已完整指定美术时，不额外叠加配色规则。用户明确要求改色时只改变获准部分，不违反故事明确事实。
- R7. 无足够证据、方向并列无法区分或与用途不相容时，不强行添加情绪配色。产品图、事实记录、标准视图不得因情绪配色改变应准确呈现的对象颜色。
- R8. 不建立“悲伤等于蓝色、快乐等于黄色”等硬映射。相同情绪允许不同配色关系；多候选时仅在未锁定维度探索，不把换色当作构图或媒介多样性的替代。
- R9. 用户可在聊天中直接表达“同色系”“互补但柔和”“暖色再少一点”“保留原图颜色”等要求，无需专业角度术语或额外设置页。明确的当前修正优先于自动判断。

**参考图策展与提示词边界**

- R10. 后续参考图分析在既有开放分类之外，观察色相聚散、主辅面积、饱和度、亮暗块面、颜色的空间位置与局部笔触尺度，并观察这些方法如何与媒介、构图协调；混合或不确定时保留观察依据，不硬归类、不补造角度或比例。已有记录兼容，不要求全库重新分析。
- R11. 借用参考图的配色方法不等于继承原图具体色板、人物或情节。原图色板仍须有故事或用户的相应色彩证据才可采用；艺术家名字、原图私有路径和污染文字不进入自动提示词。新增或大改美术卡继续默认 draft，筛选后才可激活。
- R12. 最终给图片模型的是一套相容、可观察的联合美术指令，沿用单次权威提示词编译；已选方法必须到达最终提示词，不能只有检索标签。不在多个环节重复追加或产生冲突。角度与比例用于指导，不承诺生成模型会严格复现数值。

**联合美术语言**

- R13. 明暗不仅表示整体亮或暗，还表示亮暗块面的相对大小、连接与分离、视觉重心及边缘软硬；与构图和光线一起组织可读性。局部位置按本镜头安排，继承全局配方不等于照搬上一张画的亮点、人物或物件位置。
- R14. 整体配色与局部用色可以不同。允许整体低对比而局部有细小冷暖并置，或以中性色骨架承载少量彩色点触；须说明尺度与主次，不能把局部互补误写为全幅撞色。透明叠染、彩铅叠色、不透明色面和点触并置等颜色交接方式须与已选媒介相容，不独立随机叠加。
- R15. 一个主导美术语言统领颜色、明暗、构图和笔触；最多保留既有数量内的相容辅助效果。艺术家参照尽量落到有依据的作品、时期或可观察方法，不把名字视为固定色板，不凭空鉴定作者或编造出处。已确认的组合风格不自动拆换；证据不足或存在无法消解的冲突时，保留高优先级方案、停止冲突维度的自动补充。
- R16. 聊天修正能够针对颜色面积、明暗块面、重心或媒介等可辨认部分生效，不无故重选整套配方。实际视觉验收同时检查灰度可读性、色彩焦点、媒介一致性、事实保留和跨故事多样性；提示词检查不能单独证明美观。

## Acceptance Examples

- AE1. **Covers R1–R5, R8.** 当前表达为“孤独，但还有一点期待”，且无锁定色彩时，可以选择大面积低饱和冷色与远处少量柔和暖色光点形成互补；也允许其他有依据的方案，不因“孤独”必选蓝色。不凭空增加人物或象征物。
- AE2. **Covers R3, R9, R12.** 用户说“互补，但不要刺眼”，输出体现主次面积、柔和饱和度和有限对比，不自动解释为两种高饱和颜色各占一半。
- AE3. **Covers R5, R6, R9.** 用户当前说“我很难过，但画面想要热烈的红色”，落实红色要求，不用悲伤标签覆盖为蓝色；不继承以往情绪。
- AE4. **Covers R6, R8, R12.** 已确认封面为墨绿与米白，续页继承其色板，不因本页情绪改变而新增橙色；只在未锁定的明暗或面积等维度调整。完整作者美术方案不再叠加自动配色。
- AE5. **Covers R5, R7.** 用户没有表达情绪，故事和镜头也无相关线索时，不根据年龄、旧画像或常用配色硬选关系。标准视图保持对象实际颜色。
- AE6. **Covers R6, R9.** 原图人物衣服为红色，用户要求保留人物身份和衣着时，不为了单色或互补效果把衣服改蓝。用户明确允许改背景色时，变化范围只在背景。
- AE7. **Covers R2, R10, R11.** 参考图兼有邻近色背景与局部互补点睛，可以同时记录两种观察；无法可靠判断比例时记录“大面积背景、小面积点睛”，不编造百分比。提取的方法不自动携带原图蓝橙色板。
- AE8. **Covers R6, R8.** 多候选已有指定色板时不擅自换色；未指定时允许不同配色方法，但仍须在既有要求下产生真正的构图或媒介差异。
- AE9. **Covers R7, R12.** 两种方案证据相当时不强行附加其中一种；保留上游颜色与模型开放空间，不生成两套相互否定的色彩指令。
- AE10. **Covers R1, R4, R13.** 两套方案都含大面积浅色和小面积深色，若其亮暗连接和位置不同，提示词能分别表达这种组织差异，而不是只写同样的“偏亮、低对比”。具体位置不跨镜头照搬。
- AE11. **Covers R10, R12, R14.** 参考图远看统一柔和、近看有细小冷暖点触，记录整体关系与局部关系；用于新图时只在合适媒介中表达局部并置，不生成各占半幅的互补色面，不继承源图物件或色名。
- AE12. **Covers R6, R14, R15.** 用户指定彩铅和柔和叠色时，低优先级的不透明厚涂或高密度点彩要求不得并列追加；保持用户媒介，保留兼容部分。旧自由文字无法可靠判断时不猜测重写。
- AE13. **Covers R11, R15.** 已确认的常玉／Seurat／吴冠中组合卡继续保留其概括色面、书法轮廓与局部点触语言，不因艺术家标签拆成三张自动卡；新增作品参照只有依据才记录，名字及作品出处不进入自动生成指令。
- AE14. **Covers R6, R8, R9, R16.** 用户说“别这么居中，亮面移到侧边，颜色保留”，只在获准的重心和亮暗位置调整，不换色板或媒介。若要求与锁定布局冲突，保留限制并在聊天说明，不静默解除锁定。

## Success Criteria

- 用户在聊天中即可指定或修正配色关系，无需学习色环数值或使用新界面。
- 提示词可区分颜色名称、色相关系、面积、强度和位置；明确要求、锁定参考及无证据场景满足上述验收案例。
- 后续视觉验收能观察到关系和主次，而非仅出现几个颜色名称；同一情绪不持续产生同一种固定配色。使用同一内容比较不同关系，并保持媒介、构图等其他条件可比，由用户评判适配与美观。
- 联合配方能区别整体与局部用色、明暗块面和媒介行为，不同时输出相互否定的美术方法。视觉验收另以多个故事检查重复构图、固定画风与事实保留，不将颜色变化当作多样性已达标。
- 需求可直接进入实施规划；文档与提示词检查不替代真实出图质量验收。付费分析或出图须遵守既有确认规则。

## Scope Boundaries

- 不新增界面、色环编辑器或用户设置项。
- 不建立心理学色彩诊断或固定情绪到颜色的映射。
- 不改变故事事实、已锁定角色外观、构图规则或现有主风格/辅助效果数量限制。
- 本次需求整理不重新分析图库，不训练模型权重，不调用付费模型、不自动生成样图、不合并或推送 Git。
- 不以像素级色相分布检测作为首版前置条件，不保证生成图严格符合角度或百分比。
- 不增加生成后的自动重着色、灰度检测或自动评美服务，不为每次生成新增分析模型调用。
- 不建立艺术家固定调色盘、扩建通用美术规则框架或自动重写已确认的 active 卡片。

## Key Decisions

- 配色关系与具体色板分开：可借用结构，不让参考图颜色覆盖新故事。
- 情绪到配色采用候选关系而非唯一对应：保留叙事和美术多样性。
- 色相关系、面积、强度与位置联合判断：互补可以柔和，单色也可以富有层次。
- 从独立配色升级为联合美术配方：现有主导美术语言约束颜色交接方式，明暗和空间组织共同建立视觉层级；局部变化不破坏整体方向。
- 艺术参照以方法和证据为依据：作品／时期是内部策展信息，不作为固定色板或自动作者鉴定；既有组合卡继续保留。
- 沿用聊天入口和既有提示词保护边界：不增加界面或第二套编译规则。

## Dependencies / Assumptions

- 相关能力与不可破坏约束以 `docs/features/feature-ledger.json` 为准：`semantic-art-prompt-library` 为 partial，`unified-static-image-prompt` 为 working，`private-art-curation` 为 observing。本文不把这些能力或新增配色能力升级为已完成。
- 美术卡继续遵守人工筛选、内部艺术家参照和当前情绪隔离；图库继续只消费清洗后 ready 的 DNA，付费分析必须显式确认。
- 既有相关入口见 `server/services/renderGate.ts`、`server/services/styleLibrary.ts`、`server/services/artRepository.ts`、`shared/artReferenceTags.ts` 与 `docs/style-library/_TEMPLATE.yaml`；具体改动位置由规划核对。
