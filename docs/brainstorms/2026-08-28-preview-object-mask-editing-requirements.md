# Preview 点选物体局部修改

## Summary

在 Preview 中增加点选物体的局部修改流程：系统自动识别物体轮廓，用户确认选区并输入修改要求后，只重绘蒙版内的内容，结果作为可审阅的新候选保存。

---

## Problem Frame

创作者有时只想修改画面中的一个物体或细节，但目前 Preview 的图片编辑偏向整张画面的构图、旋转、文字和 OCR。若把局部要求交给整图重绘，人物、背景、构图和其他已经满意的像素也可能发生变化；视频画面还需要创作者先自行理解抽帧与图片编辑之间的关系。

---

## Actors

- A1. 创作者：在 Preview 中选择物体、检查自动识别范围、描述修改并决定是否采用结果。
- A2. 系统：准备静态画面、识别物体轮廓、约束可修改区域，并保存生成候选和费用记录。

---

## Key Flows

- F1. 静态图片局部修改
  - **Trigger:** 创作者在静态图片 Preview 中进入区域修改并点击一个物体。
  - **Actors:** A1, A2
  - **Steps:** 系统识别并展示物体蒙版；创作者确认或重新点选；输入修改要求；确认预计费用；系统只在蒙版内生成新内容；创作者审阅并选择是否采用。
  - **Outcome:** 原图保持不变，新结果成为带来源关系的候选；只有明确采用才更新当前画面。
  - **Covered by:** R1-R9
- F2. 视频当前帧局部修改
  - **Trigger:** 创作者暂停视频并对当前画面发起区域修改。
  - **Actors:** A1, A2
  - **Steps:** 系统先自动抽取并保存当前帧，再进入与静态图片相同的点选、确认、局部生成和采用流程。
  - **Outcome:** 修改发生在独立静帧上，原视频素材不被改写。
  - **Covered by:** R2, R4-R9

---

## Requirements

**进入与选区**

- R1. 静态图片 Preview 必须提供明确的区域修改入口；进入后，创作者点击画面中的物体即可请求自动轮廓识别。
- R2. 视频只有在暂停状态才能进入区域修改；系统必须先自动抽取当前帧，抽帧成功后再允许选择物体，原视频保持不变。
- R3. 自动识别完成后必须以清晰的边缘和半透明蒙版显示实际可修改范围，不能只显示一个抽象状态或文字描述。
- R4. 创作者必须能取消选区或重新点击另一个位置替换当前选区；识别失败时不得自动退化为整图重绘。

**局部生成与保护**

- R5. 创作者确认选区后才能输入并提交修改要求；生成时只有蒙版内像素允许变化，蒙版外画面必须作为受保护内容保留。
- R6. 每次付费提交前必须显示预计费用并取得明确确认；选区、底图或修改要求发生变化后，旧的费用确认不得继续使用。
- R7. 局部生成失败、超时或返回未知状态时，不得覆盖当前画面，也不得自动创建另一笔付费任务。

**结果与既有功能**

- R8. 生成结果必须作为新候选保存并保留原图、来源画面、选区、修改要求和费用记录；只有创作者明确采用后才更新当前镜头画面。
- R9. 现有构图、旋转、文字、OCR、暂停抽帧和普通整图改图能力必须继续工作；区域修改不能改变这些能力原有的保存语义。

---

## Acceptance Examples

- AE1. **Covers R1, R3-R5.** 给定 Preview 显示一张含人物和桌子的静态图片，当创作者点击桌上的杯子时，系统显示杯子的轮廓蒙版；创作者要求“改成蓝色陶瓷杯”后，只有蒙版区域被交给局部重绘，人物、桌面和背景保持受保护。
- AE2. **Covers R2, R8.** 给定 Preview 正在播放视频，当创作者尝试区域修改时入口不可用并提示先暂停；暂停后发起修改，系统先抽取当前帧，最终候选属于该静帧，原视频仍可正常连续播放。
- AE3. **Covers R4, R7.** 给定系统没有识别出创作者点击的物体，当识别失败时，界面保留当前原图并允许重新点击或退出，不提交整图生成，也不产生新的生成任务。
- AE4. **Covers R6-R8.** 给定选区和修改要求已经得到报价，当创作者重新点选另一个物体时，原费用确认失效；新报价确认前不得提交，生成成功后也必须等待创作者采用。

---

## Success Criteria

- 创作者可以从 Preview 通过一次点选获得可见、可确认的物体轮廓，并完成只影响该区域的修改。
- 视频当前帧局部修改无需创作者手动管理抽帧，同时不会破坏原视频或正常播放。
- 未确认费用、识别失败、生成失败和未采用候选均不会改写当前画面。
- 实现与验证能够证明蒙版外像素受保护，且现有 Preview 图片编辑功能无回归。

---

## Scope Boundaries

- 第一版不支持同时组合多个不相连的物体选区。
- 第一版不提供画笔式增加、擦除、羽化或逐像素修整蒙版。
- 第一版不在播放中的视频上跟踪移动物体，也不把同一蒙版传播到连续多帧。
- 第一版不自动采用生成结果，也不删除原图或未采用候选。

---

## Key Decisions

- 以“点击物体自动识别轮廓”为主要交互，而不是矩形框选：更符合创作者按对象表达修改意图的方式。
- 先显示并确认蒙版，再允许生成：让创作者在付费前知道系统究竟会修改哪里。
- 视频沿用暂停后自动抽帧：所有局部图片修改落在独立静帧上，视频素材保持不可变。
- 失败时保持原图并允许重试：绝不为了完成请求而静默扩大到整图重绘。
- 结果采用候选制：生成成功不等于替换成功，最终画面仍由创作者明确决定。

---

## Dependencies / Assumptions

- 自动物体分割服务和透明遮罩局部图片编辑服务可用，并能返回与 Preview 底图对齐的蒙版。
- 局部生成继续遵守现有的用户归属校验、费用确认、任务恢复和候选采用规则。
- 自动分割对小物体、透明物体或边缘模糊物体可能失败；第一版通过重新点击或退出处理，不承诺手工修边。
