# 记忆仓库默认故事范围修复

日期：2026-10-12

## 原因

桌面 MemoryWarehouse 使用账号级 list/sync，既没有传当前故事，也没有明确标示账号范围，因此从一个故事进入仓库会看到另一个故事的对话。账号归属检查原本存在；这是同账号的展示范围问题。手机已有 forStory/syncStory。

## 修复

- 桌面默认复用 forStory/syncStory，仅展示当前故事及用户主动组合到文字版本中的来源卡片；跨故事来源标为“已引用到当前故事”。
- 原“全部记忆”按钮改为“当前故事 / 账号全部记忆”选择，保留主动跨故事选卡，不增加按钮。
- 归档状态与分页使用同一范围；新增卡片绑定当前故事；切换故事重置范围和分页。
- 未保存故事禁用故事读取，不回退显示账号缓存。保存首张故事卡片时先走已有显式故事保存。
- 不删除、迁移或批量重写现有记忆；文字来源快照、账号隔离和手机入口保留。

- 覆盖：同账号其他故事/无来源记事排除、跨账号拒绝、归档隔离、故事内分页、主动引用卡片保留、账号级缓存不混入默认视图、未保存故事不显示缓存。
- 环境检查：仅主仓库端口 3000 运行。
- 类型检查和构建通过（构建保留已有的大包提示）。功能账本 53 张卡校验通过；`pnpm feature:validate` 受 tsx IPC 权限限制，使用 `node --import tsx scripts/validate-feature-ledger.ts` 执行同一校验脚本通过。`git diff --check` 通过。
