# 微信导入书稿章节展示 — 2026-11-02

## 问题与范围

微信故事原按小程序章节导入为网页同一本书稿里的 `heading1` 及其 `parentId` 子模块，但默认全部展开且不显示章序，长文和图片混在一起。利用原有 `wechatImport.modules` 凭据识别导入的章节标题，按书稿当前顺序显示“第一章、第二章……”（English/Français 使用 Chapter/Chapitre 数字），每章默认收起；点章名展开正文、图片，再点章号收起。非微信导入的普通书稿继续原样使用画布和既有折叠功能。

此展示状态仅存于当前打开的界面，重新打开回到默认收起；未写入现有正文、字号、图片、模块 ID、父子关系和版本，没有重新拉取或导入微信故事。章节标题仍可在展开后编辑，既有排序、删除、撤销和保存路径仍沿用。原来根据小程序布局携带的字号不会被改写；如果来源的字号在网页中看起来过大，仍可以使用原有字号操作调整，不能断言其视觉尺寸已自动修复。
