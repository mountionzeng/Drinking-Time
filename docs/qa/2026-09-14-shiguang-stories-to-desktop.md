# 拾光家忆故事进入电脑验证

## 固定方向

数据只从微信里的“拾光家忆”进入电脑网页版。旧的“验证 Drinking Time 邮箱，把网页故事导入微信”页面和云函数动作已移除。

## 用户流程

1. 在拾光家忆打开“我的 → 在电脑上继续”。
2. 页面只列出当前故事架上的有效故事，最近删除中的故事不参与传输。
3. 用户选择一个故事并再次确认，微信云函数从可信 OPENID 派生不可逆主体，以 HMAC 签名上传故事快照。
4. Drinking Time 将快照写入该微信主体的独立账号，返回五分钟、一次性的六位电脑登录码。
5. 电脑登录页选择“微信登录”并兑换；故事出现在该账号的故事库，可继续做分镜和视频。

## 数据与安全边界

- 客户端不能提交 userId 或明文 OPENID；服务端账号只从签名主体解析。
- 快照包含记忆正文、标题、摘要、人物、地点、情绪、章节正文和照片引用。
- 相同来源和相同修订重试复用已导入故事；新修订创建新快照，不覆盖电脑端编辑。
- 当前幂等锁覆盖单个服务进程；如果未来同时运行多个服务进程，同一快照在极窄并发窗口内仍可能重复导入，需要用数据库唯一约束彻底消除。
- 书稿照片当前只在手机本地，传输保留 photoId 引用，不声称已经传输照片字节。
- HMAC 桥和电脑码均默认关闭；上线需要在网页服务端与微信云函数配置同一条至少 32 字节的密钥。
