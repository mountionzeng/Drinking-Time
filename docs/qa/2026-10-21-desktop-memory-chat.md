## 变化

- 顶栏新增独立“回忆”，显式打开账号全部回忆；不依赖当前文字栏目。
- 原文字下方的“记忆仓库”入口迁入左侧对话框，显示“记事与文章来源”，默认只读当前故事的记忆及已引用来源；原选卡排序成文、归档恢复、手写卡片能力保留。

- 默认无范围的旧调用仍打开故事记忆；未保存卡片或生成中的操作阻止静默切换范围。
