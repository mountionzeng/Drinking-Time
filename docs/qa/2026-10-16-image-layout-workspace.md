# 图像 / 排版工作流

用户确认：排版改字仅用于这套成品，原文不变；减少外层框，使用左右空间放页面与可选图片。

## 实现

- 顶层图像内分「图像」「排版」，同一编辑会话切换保留。图像保留原封面、插图、底图、收费生成与旧画册入口。
- 排版解除工作区宽度和套框，直接显示左侧页缩略图、中间画布、右侧图库；默认进入编辑，无需反复完成/返回预览。
- 点击已有图片顺序加入当前页，拖入则落在指定位置。上传PNG/JPG/WebP至本机图库，与正式故事资产隔离。生成入口沿用原费用确认，候选返回图库后手动加入。
- 新增文字在画布内输入，实时预览，失焦验证保存。自动排列避开手动摆放；不足时新增页面，最多九页，超限原子失败。支持删除模块、撤销重做与显式整理这一页。
- 老草稿没有手动定位标记时保留所有位置。正文或设置来源变化时保留旧草稿并要求显式使用更新后的内容。
- 下载、复制、分享使用当前模块文档的同一绘制器，PNG为1800×2400；不写回原文。没有封面且无历史设置时，先排出纯文字页。

## 验证

在主仓现有3000服务、用户浏览器当前桌面窗口中完成：

1. 确认图像/排版入口、全宽三栏与右侧素材可见，旧草稿和原有几何位置保留。
2. 新增临时文字，输入后画布更新，点击外部完成输入；用界面删除临时模块，原文未保存或修改。
3. 点击未使用的已有图片加入成品，空间不足时由4页续至5页。下载该页并检查1800×2400 PNG，图像正常渲染。
4. 从右侧图库用真实鼠标拖放到纸上，确认出现新的图片模块与重叠提示；一次撤销还原。
5. 恢复原有4页内容；切换子栏目检查编辑会话保留。热更新后的重新挂载恢复了本机草稿。

## 实际范围

- 本机图片与草稿不跨设备同步；没有本机图库删除管理或跨页手动拖移。原生文件选择器未在本次浏览器验收中选入测试文件，格式/体积处理由自动化测试验证。
- 本次没有提交付费生成或第三方分享，生成报价与服务链路复用已有实现。
- 改整套字体、封面、底图仍在图像栏目；来源基线变化采用现有显式重新打开策略。新增长段落超过一页会提示拆段，不静默缩小。
