# 2026-11-03 书稿生成文字格式修复

用户反馈生成正文露出 `**`，明确要求保留加粗和标题排版，公式继续按 LaTeX 显示，不增加按钮。

## 根因与修复

原生成提示只要求“不使用 Markdown 粗体”，模型偶尔仍返回 `**标题**`；服务直接持久化，书稿阅读器只解析数学分隔符，文字标记原样显示。已用真实生成服务与模拟模型复现，回归先红后绿。

- 书稿的「生成文章／生成新版本」请求增加可选 `outputFormat: book-latex`。提示词要求普通正文、LaTeX 文字强调与标题，版本更新为 `text-draft-two-pass.5`；输出在持久化前规范成 `\textbf{}`、`\section{}`、`\subsection{}` 等安全文字格式。
- 只转换模型新生成的正文片段，再拼接选区外原文；标题、标签、选区外内容、保存CAS和生成认领流程保留。没有格式参数的手机与旧平台请求维持原输出约定，未修改跨平台导出服务。
- 书稿聊天的一键改写也规范 replacement；带书稿改写提议的聊天回复复用阅读渲染器，不显示新的 LaTeX 文字命令。
- 书稿阅读层以 React 的 strong/em/heading 节点显示有限的文字格式，兼容旧稿的成对 `**` / `__` 与 Markdown 标题。公式继续用原 KaTeX 安全配置。代码、转义字面符号、未闭合标记和无效公式原样保留，不解释任意 HTML、TeX 文件或宏包。
- 旧稿仅改变阅读显示，不迁移或静默改写草稿。原 textarea、字符偏移与源码复制流程保留；点击编辑时显示源码，失焦恢复排版。沿用已有预览高度测量和跨模块选择机制，无新增按钮。
