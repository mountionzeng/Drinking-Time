# 故事创作笔记与好友来信

## 个人笔记

- 网页的「开启新故事」会保存空白故事，并立即提供「聊天目录 → MEMORY.md」。当前故事的对话、单独留的笔记、纠错、确认的版本和镜头调度按标题呈现。
- 「单独记一条」可留下作者要长期保存的文字。修订后旧记忆可在记忆仓库的归档中回看，当前 `MEMORY.md` 读到新内容。
- 书稿生成和续聊把笔记当作当前故事的来源。只选指定记忆卡生成时，依据仍限于选中的卡片。

## 好友来信

- 在网页邮箱选联系人，点「分享创作笔记」，填写明确同意共享的 Markdown。每次发布留有独立版号和正文。打开最近一次发出的来信可以修改这份共享稿。
- 收件人可展开来信看全文和改动。首次可选择采用到当前故事，或新建故事。后续采用加入同一个故事的来源笔记。展开来信时也可说“把这段用到我这版里”，再确认目标。
- 好友收到的是发布的文本快照。发送者和接收者的其他故事资料继续由各自账号持有。

## 本地验收

- 本地 3000 从真实故事菜单新建、打开空白笔记、补记、修订、刷新及重开通过。用《满城》回看当前文字版与已确认镜头，同时复核测试故事中的内容没有进入《满城》。
- tRPC 两个测试账号走通发布 V1、B 采用到已有故事、A 发布 V2、B 回读具体改动及 V1，核对未采用时的独立续写与双方私有内容。另使用隔离 MySQL 验证同一流程以及既有邮箱回归。
- 已测试展开来信后由聊天确认采用，以及切换上下文后旧确认失效。公开发送的内容需要使用邮箱的发布入口。
- 本地改动未发布。真实浏览器双账号互传待独立登录环境验收。
