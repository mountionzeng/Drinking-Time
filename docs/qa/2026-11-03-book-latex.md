# 2026-11-03 书稿 LaTeX 公式显示

用户明确选择“把 LaTeX 显示成排版好的公式”。本轮增加阅读显示，沿用原文字编辑与保存，不增加常驻按钮。

## 行为

- `$...$`、`\(...\)`显示行内公式；`$$...$$`、`\[...\]`显示独立公式。支持 KaTeX 的分式、根号、上下标、积分、求和、矩阵等语法。
- 平时显示排版结果；点击原文字区域编辑原始 LaTeX，失焦后恢复公式。原 textarea 始终挂载，不把渲染HTML写入正文。
- 新建/粘贴的完整多行公式保存在同一文字模块，行数仍通过原 writingStyle 保存。公式内部Enter保留换行；普通文字仍按原规则拆段。已有稳定模块边界不自动合并。
- 跨模块拖选时先显示源码再测量字形；复制得到源码。原选区、移动/缩放、改写替换、撤销与CAS保存继续使用原流程。
- 公式实际高度参与页面布局，避免较高分式/矩阵挤压下一段。新增ResizeObserver及字体加载监听有卸载清理。
- KaTeX 0.19.1及字体随应用打包，不请求CDN。`trust:false`、宏展开/尺寸/输入长度上限；无效公式保留源码，普通美元金额、转义和代码片段不误渲染。
