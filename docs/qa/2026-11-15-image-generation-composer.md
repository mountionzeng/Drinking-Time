# 2026-11-15 生成描述编辑与仓库图片引用

## 用户入口与行为

视频分镜的普通 MJ「生成图片」确认窗口改为可编辑描述与同屏图片仓库。描述中图片以缩略图和镜头/图片标签呈现；悬停或键盘聚焦可看大图、真实像素尺寸、日期和已有描述。仓库支持搜索，点击在光标处插入；重复引用只占一个参考名额，删除最后一个引用即取消这张图。删除所有内容参考仍保留独立全片画风。

本次修改仅用于本次生成，不改书稿、分镜原文或已采用图片。仍须确认算力；保留最多4个内容参考和显式资产版本，已有改图、聊天报价与父批次确认路径不变。新结果仍为候选，不自动采用。

服务端识别 `renderReferences.instructionMode=composed`，以用户编辑后的描述为准，不重新拼入旧镜头或相邻镜头事实。保留已确认画风及明确选择的资产合同，按同一顺序提交引用；本人/故事归属、费用和未知任务保护保持。描述长度与接口2000字符上限一致，组合后超过供应商限制会在提交前拒绝，不静默截断。
