# 手机故事对话与回忆入口收敛验收

日期：2026-10-21。用户明确取消具体故事的回忆阶段，要求手机与电脑共用对话能力。

## 入口与数据

- 故事详情改为文字／图片／视频，默认文字；首页账号回忆库保留。
- 首页“继续对话”直接打开对应故事的小忆。故事图片未选中模块时也保留故事上下文，不会误开新故事。
- 故事对话显示同一权威聊天记录的完整历史，取消旧本机基线过滤；文字全文、选区、排版模块仍传递原上下文，普通故事聊天直接发送用户原话。
- “对话内容”保留聊天目录定位、单条图文、记事修订、原文归档及文字生成时的来源快照；可明确引用选中内容继续聊，用户原话与助手整理仍区分。
- 新增逐条复制和语音草稿入口。语音复用桌面 useVoiceInput 与 voice.transcribe，用户明确开始录音和停止转写，识别结果只追加输入框，由用户确认发送。
- 录音／转写期间阻止切换上下文；共享语音 hook 拒绝卸载后的异步授权和转写回调，停止音轨，防止串入其它故事。
- 未发送内容、失败队列、文字版本和 CAS 冲突保护继续保留。没有服务端接口、数据库迁移、环境文件、nginx 或证书变更。

## 验证

- 手机与语音／语言定向27文件177项通过；主仓完整663文件5,634项通过，18个MySQL文件65项跳过。TypeScript、65卡功能账本、环境闸门及33条迁移基线通过。
- 新增语音测试覆盖迟到权限、迟到转写、正常识别与麦克风释放；故事聊天测试确认完整历史可见、打开不发送、普通故事原话不包装成回忆。
- 主仓3000端口390px：三个故事阶段、图片页小忆所属故事、完整12条历史消息、复制入口、内容目录与引用返回均实际检查。
- 320px：对话宽300px、页面宽320px，无横向溢出；语音可打开“开始录音”入口，未申请麦克风或调用真实转写。
- 浏览器只做阅读、入口与引用切换；未发送模型请求、未保存业务正文、未购买生成。
- 页面继续沿用浅绿纸感与小鸟弹层。截图临时保存在 /tmp/mobile-chat-390.png 与 /tmp/mobile-chat-320.png。

## Known gaps

- 真机iOS/Android麦克风权限、实际语音识别、软件键盘、系统字号及双设备公网同步尚未实测。
- 手机媒体导入仍仅保存素材及说明；电脑聊天的识图归类、图片提取／重绘、声音导演等高级素材工具没有全部搬入。本次对齐完整记录、文字对话及生成／采用、复制与语音入口，不宣称高级工具全量一致。
- 本轮无 TEST_MYSQL_DATABASE_URL，MySQL专项保持未跑；未用生产库作为测试库。
- 朋友分享回来提醒的正式双账号验收由用户自行体验，未借本轮测试宣称完成。
