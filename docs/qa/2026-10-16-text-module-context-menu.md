# 文字模块右键菜单与叠图样式

## 实现

- 文字模块右键菜单：正常 / 加粗提亮、半透明底色开关、删除文字模块。沿用现有Radix菜单与界面颜色，支持Shift+F10、菜单键、方向键及Escape；编辑文字时保留浏览器原生文本菜单。
- 正常模式为原深色文字；提亮模式为浅色粗字。单字等距加笔画保留原段落换行与位置，兼容五种已有字体。未开底色时保留轻微深色描边，避免浅色字在浅图上消失。
- 底色仅包住文字及少量内边距，无花纹、边框或阴影；正常文字配80%纸色，提亮文字配72%深色。跟随模块移动缩放，画布、缩略图和PNG使用同一绘制器。
- 文字统一在图片上方绘制与接收指针事件，不改变文档原顺序及自动排版顺序。图文叠放不再显示误导性的重叠警告，同类模块重叠仍提示。
- 可选样式字段兼容旧草稿。右键删除与样式修改使用原撤销/重做与本机保存；不修改原文、图片素材、正式封面或既有分享。
