# 书稿合并为图像 · 本地验收

用户确认三个入口共用聊天方案：多资源右键“合并为图像”、基于当前内容生成→图片、聊天里明确要求生成图片。未选模块时使用全文；原模块保留，新结果放在素材之后。沿用现有颜色、字体和聊天定位区，无新增常驻工具栏。

## 实现与保护

- ChapterTextModules 通过既有撤销/章节 CAS 保存链插入结果。所选图片与文字按正文顺序快照，空白块跳过；音频明确拒绝，不悄悄遗漏。右键纯图片选区也能使用；图片多选不再被文字范围选择清空。
- 方案无需额外模型请求，直接汇总所选图和已有想法；轮次修改沿用原素材、最新结果和此前要求。多个确认前的补充也累计保留。
- 仅这条新路径显式使用 302 gpt-image-2.5-sunburst / high / 1536x1024 / 单图；图片经统一 renderViaGate 原图优先分支，文本创作走普通网关。原 MJ/GPT2、局部修改、视频和音乐入口保留。
- 每轮方案内确认费用。费用为按现有 302 token 单价和汇率、保守输入/输出预算计算的产品报价；不是供应商实际账单，也不是此前单张样图约 ¥0.32 的实测用量估算。账本按所确认报价结算。
- 使用已有 bookModuleImageTasks 的事务存储，无新增迁移；合成任务独立 moduleId 命名空间。每轮有唯一后继任务，先持久占位、再预占费用、单次提交；回执先保存，之后只 GET。未知结果冻结，明确失败释放；候选图片与任务完成原子入库，结算幂等。原始模块变化或换故事/账号不会写错位置，结果仍在仓库。
- 汇聚动效只画短暂轮廓、不复制正文 DOM、不挡交互；减少动态效果设置下关闭。

## 验证

- 最终 11 文件 216 项回归通过：新增共享/服务端/供应商参数测试，以及既有 imageGen、原任务恢复、网关、文字编辑、多选和跨模块范围测试。
- 新增方案组件 4 项测试通过：确认前不购买、双点只一次、恢复只查询、切换期间不提交、结果只插一次、用户满意后结束。
- 最终 pnpm check、git diff --check、pnpm feature:validate（82 卡）均通过。
- 主仓 localhost:3000 的独立测试标签实点：两个图片模块多选→右键合并为图像，出现两张参考图与方案；菜单图片在无选区时带入当前全文 5 图与 26 段文字。随后验收图文混选：2 图 + 1 段文字正确汇入同一方案；聊天“帮我生成一张图，保留参考图的手绘线条”触发全文方案，继续输入“不要额外添加阴影”保留此前要求。未点击费用确认；未调用新付费生成。截图：/tmp/book-image-composition-20261104.png。

## 限制

- 新整条链尚未购买真实图片；模型此前双图单次试验另见 outputs/sunburst-trial-20261104。新任务恢复和账务通过模拟验证，生产 MySQL 未复验。
- 首次生成前未确认的方案只在当前页面；已提交轮次与结果持久保存，重新选同组模块可恢复。
- 最多 15 张不同原始图片，保留一位给上一轮结果；总输入最多 200 个非空块/30000 字符，提交前另校验完整提示词（有图最多11000字符、纯文字最多5000字符），超出时明确拦截，不截掉参考图。供应商超过两张输入的实际效果待验。
- 生成不是像素级复制；后续满意度仍需用户验图。关闭方案或页面后不会继续前台轮询，重开同组素材可取回。
