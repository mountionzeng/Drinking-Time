# 2026-11-03 文章粘贴与拖入图片

用户要求：从其他地方复制图片，或本地拖入多张图片，在文章指定位置成为图片模块，同时素材仓库可见。不增加常驻操作按钮。

## 接入

- ChapterTextModules 的当前书稿入口增加透明事件边界 BookImageImportBoundary。剪贴板图像文件/单纯图片HTML（可包含多图）走上传；普通文字、带文字的混排HTML仍走原文字粘贴，避免悄悄丢字。音乐/转换弹窗的粘贴不被书稿接管。
- 本地拖放 FileList / DataTransferItemList 支持多图。拖入时根据可见模块位置显示插入线，按原文件顺序在落点创建独立图片模块。粘贴在普通文字光标处拆分前后文，文字不删除；标题、媒体、公式内部保持整体，在模块后插图。
- 复用 creationAgent.importStoryMaterial：原图保存为稳定媒体地址并归入当前故事的仓库，不绑定镜头、不设封面、不调用AI。刷新 captured story 的 storyImages 和 storyMaterialState 查询。保留PNG透明度和原始图片字节。
- 一次最多20张，单张30MB，PNG/JPG/WebP。网页图片只在来源允许浏览器读取时导入；受限来源给出先保存本地再拖入的提示，不添加服务端代理。HTML只在 inert template 中解析，不渲染任意标记。
- 上传按顺序执行，不自动重试。成功图片合为一次编辑，失败项目单独提示；一次撤销恢复原文，但仓库保留已上传原图。
- 上传前固定模块ID/光标/原文；结束时使用最新模块树，保留其他位置的新编辑。原位置被删除或对应文字变化则不插入，已上传图片留在原故事仓库。切换故事、账号、scope或卸载后不得把迟到结果写进新编辑器。
- 不改保存CAS、历史候选、原公式显示、跨模块选字、分组移动/缩放或已有排版本机图库语义。
