# 聊天底部留白与状态提示

日期：2026-11-04。状态：本地完成，未提交、未部署。

用户希望压缩截图中输入框上方的留白，将多条提示逐条淡入淡出，透明空间留给聊天。

## 实现

- 沿用现有 Logo、输入框、工具按钮及主题。去掉输入区额外上间距，聊天滚动区底部 padding 从 20px 减到 4px；清除滚动区域的底色、模糊和阴影，输入区保持透明。
- 在 Logo 旁以固定高度单行展示真实生成/读取/思考状态和当前上下文。多条时每 4.2 秒轮换，淡入/淡出各 220ms；悬停暂停并通过原生 tooltip 查看完整信息，不新增按钮。
- `prefers-reduced-motion` 下停止自动轮换与渐变。屏幕阅读器读取完整状态列表，只在实际状态改变时更新，不随每次视觉轮换重复播报。
- 视频进度回传到同一行，不在聊天末尾重复占据一段；按账号/故事/作用域隔离，完成或卸载清空。独立使用 BookVideoChat 时保留原来的进度文字。
- 原视频确认、费用说明、失败提示与排版记忆详情保持可访问；只调整展示，不触发生成或修改聊天/正文。
