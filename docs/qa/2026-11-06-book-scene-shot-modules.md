# 书稿章／节／场／镜头模块

2026-11-06，主仓 main 本地实现；未提交、push 或部署，未调用付费生成，未改用户真实书稿。

## 已实现

- 复用模块格式菜单新增「转换成一场」「转换成一个镜头」。`scene` / `shot` 存在 writingStyle 的格式中，以稳定 ID 和 parentId 组织真实子树，不在正文中伪造标题前缀。
- 章、节、场、镜头按当前文档顺序显示编号，节按所属章、镜头按所属场重新计数。手工章与微信导入章统一章序；微信导入章保留默认折叠目录与仅界面的展开状态。
- 编号与可编辑标题分离，不覆盖用户手写标题。移动二场三镜到第一场第二位显示「一场二镜」，ID、图片 URL/裁切信息、台词分类、音频引用、描述和内部相对顺序保留。
- 场／镜头拖动、折叠、多选沿用完整子树逻辑；移动后同一次撤销可恢复。新增镜头标题从上一镜头内转换时提升到场内；场从上一场内转换时提升出来。拒绝把场嵌入场／镜头或把镜头嵌入镜头。上下键按同级子树排序。
- 一个镜头可包含多个文字、图片及既有音乐模块，也可只有文字或空标题；没有新增每镜素材数量限制，沿用全文长度和模块总数限制。新生成图像／音乐的源若为场或镜头标题，结果归入该容器。
- 服务端 schema、保存 CAS、重开和版本恢复支持新增格式，不需要数据库迁移或批量改写真实数据。既有文字编辑、台词标记、双栏、缩放、删除／撤销、多选、微信导入路径回归通过。

## 转视频衔接与边界

- `server/services/bookStoryboardModules.ts` 从已保存模块树按显式镜头解析，输出已有 `bookScenes` 接口，新增可选 `sourceKind: 'shot'`。稳定行 ID 为 `book-shot-{chapterId}-{moduleId}`，不使用随排序变化的编号作为身份。
- 同场多镜各保留一个预览镜头；图片仅来自该镜头子树，支持同一图片在不同镜头复用。台词逐字传递；无标记台词的显式镜头传空字符串，说明文字不作为旁白。场内说明作为该场镜头上下文。
- 模型提示区分显式镜头和旧幕式稿，沿用原禁止额外补镜的校验。没有 `scene` / `shot` 的旧稿继续走「第 N 幕」一幕一镜或原普通稿路径，其源指纹算法保持。
- 场／镜头层级、模块顺序和用途进入源指纹，移动后不能采用旧来源的方案；折叠等纯展示变化不影响指纹。
- 明确拒绝不完整的混合结构：含场但没有镜头、仍有非空独立章节未设置镜头、镜头嵌套、镜头外图片／台词、旧排版独有且未插入镜头的图片。提示整理归属后重试，不静默丢素材或猜分镜。普通上下文文字可位于镜头外。原视频接口的最多100行／图片等限制继续存在。
- 背景音描述可以放在镜头内，已有音乐模块随镜头保存和移动；**视频配乐仍沿用现有整片顺接规则，未新增按镜头自动排入点／出点、音效轨或角色声线绑定**。图片多参考及台词已接入预览，音乐精确时序仍待后续接入。
- 未做真实模型生成、付费成片、生产 MySQL 或触屏真机验收；微信章节包携带全部 writingStyle 的既有缺口仍保留。旧客户端应刷新到支持新格式的版本后再编辑。
