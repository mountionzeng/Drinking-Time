- 点镜头表图片即可选中，不自动打开字幕/变换面板；双击仍打开原编辑器。
- 聊天底部「生成新稿」在选图后变为「重新生成图」，旁边选择 `GPT Image · 改图` 或 `MJ · 重绘`。取消选图恢复原按钮。
- GPT Image 1.5 使用所选原图与原始修改要求，一次生成一张；当前报价约 ¥1.49。
- MJ 使用所选图片作参考，一次生成四张，当前报价约 ¥0.68；它是参考重绘，不承诺精确局部改动。可用时将要求整理成英文目标画面，整理失败仍保留原始要求与原图。
- 明确点击重新生成时直接进入费用确认。GPT 无需先调用聊天意图识别或图像提示词导演。接口校验报价、故事归属、参考数量与镜头身份；取消、目标漂移不会提交。
- 只调用用户选择的图片模型。失败不换模型、不静默丢掉参考图、不自动追加付费任务。
- 新版回链原图，保持未采用；原图保留。新版卡片写入故事归档，刷新后仍可选中继续修改；跟随镜头时不覆盖明确的候选选区。

## MJ 其他接口核查

供应商文档提供标准、Relax、Turbo 三组接口，主要是运行速度与价格档位，不等同于三个精修模型：

- [标准 Edits](https://doc.302.ai/317861511e0.md)：image + prompt，0.05 PTC/次。整图实测如上。
- [标准 Action](https://doc.302.ai/160578876e0.md)：taskId + customId，0.05 PTC/次。
- [标准 Modal](https://doc.302.ai/160578880e0.md)：taskId + prompt + maskBase64，0.05 PTC/次。
- [Relax Modal](https://doc.302.ai/235701267e0.md)：`/mj-relax/submit/modal`，0.02 PTC/次。
- [Turbo Modal](https://doc.302.ai/329176692e0.md)：`/mj-turbo/submit/modal`，0.1 PTC/次。

当前目录没有独立 Retexture 接口。Modal 需要来源任务与局部区域流程，不能据其存在就宣称任意本地图片可直接对话精修。未对 Relax/Turbo 逐一付费测试。
