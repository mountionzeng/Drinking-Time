# 可复用分镜稿与图片继承

## 用户目标与入口

书转视频使用同一套流程，并继承书内图片及前一版视频的生成画面。继续使用“把书做成视频”与原聊天方案确认；仅在当前对话内提供默认勾选的“先整理为可编辑的分镜稿”，不新增常驻按钮。

1. 先保存可见书页草稿。
2. 将原模块完整、连续地分组为场／镜头，保留原文、图片、音频、模块 ID、行 ID 与格式；已有场／镜头稿直接沿用。
3. 所有章节通过版本与顺序校验后原子保存，原稿写入原版本历史；模型漏项、重排、并发改稿时不保存半份书。
4. 刷新干净书页，再进入原视频方向讨论、逐镜人物／台词／画面／背景音预览与确认。
5. 只有用户明确采用当前修订，才写正式视频表格。此流程不购买图片、配音或视频。

- 当前故事 1217，章节 9：原四图 2019、2003、2004、2005 仍存在。第一、第三场此前折叠；现在折叠标题显示“含 N 张图片”。

- 采用时按稳定镜头 ID、唯一来源模块关联或旧稿精确长句匹配继承，跨发布稿版本同样沿用当前活动镜头。不得按数组位置串图；歧义／拆分／合并无法唯一对应时单独提示旧图仍在仓库。
- 手动选定首尾帧、参数与参考移除决定保留；新书内参考更新。不会将未选仓库候选、已拒绝图片或已删除书内参考自动加回。
