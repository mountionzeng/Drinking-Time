# 视频自动字幕与生成中预览

日期：2026-11-04。状态：主仓 3000 本地完成，未提交、未部署。

## 用户要求与实现

用户希望自动生成视频时同时生成字幕，画面未全部生成时就能播放，并在 Preview 显示当前镜头描述。

- 发布稿/书稿确认视频方案的共用 `confirmPublishingVideoStoryboard` 在镜头保存成功后调用字幕服务，按已确认镜头的台词/旁白创建正式字幕轨。读页面、看预览不写入；不调用 ASR、TTS 或额外付费模型。
- 自动初始化沿用 `timelineSubtitleEditing` 的归属校验、共享编辑锁、Timeline CAS 和持久幂等记录，保存失败明确提示已有方案保留并可续做，不重新生成镜头。
- 初始长台词按标点与可读长度分句，按镜头的实际绝对帧位置和时长分配显示时间，保留全部文字、英文词语和 emoji；空台词不生成字幕，被排除的镜头不占字幕时间。此时间是分镜估算，尚非逐字音频对齐。
- 已存在的正式字幕轨拥有权威，即使用户删空也不自动填回；人工改字、时间调整、原 ChatCut 字幕保留。重复确认、服务重启或初始化撤销后不重复追加。已有字幕不会随新版本静默重写，仍由用户通过现有字幕编辑入口调整。
- 复用现有走带时钟和播放按钮；播放无需等待所有视频生成。无画面时在画布显示当前镜头主体/动作描述，已有图片时显示图片，有已采用视频时沿用现有视频播放。描述始终跟随当前播放镜头，不写入字幕或导出画面，时间线空档清空旧描述。
- 没有新增常驻按钮，也没有把未生成的视频假称为可播放成片。
