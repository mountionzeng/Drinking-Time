# 电脑正文伴写与新版本流程验收

范围：电脑 `/editing`。保留现有手机入口、界面、段落整理流程；本轮不部署。此前只允许生成候选；用户后续明确要求实际点击完整四步流程，本次已点击保存并验证持久化。

## 已实现的用户流程

1. 左侧对话自动读取右侧当前正文，包括未保存编辑；注册上下文本身不调用模型。
2. 选中正文后，切换到聊天输入框仍保留选区；不需要额外的帮写按钮。
3. 对话只提议结构、逻辑、表达的修改方案。桌面单轮45秒期限、低推理强度，不自动重放结果不确定的请求。
4. 已有文章时点“生成新版本”直接生成候选。使用可见正文与最新聊天，旧历史面板选择不覆盖当前编辑。
5. 候选在右侧标明“新版本 · 待保存”；只有用户点顶部“保存”才采用。生成途中编辑或切换故事、账号、版本，不覆盖新编辑。
6. 有选区时模型只生成替换文字，服务端拼接原前缀和后缀；保存前仍是候选。
7. 普通文字可以连续发送，立即显示并按顺序处理。失败/刷新后暂停，保留原消息及当时上下文供核对，不盲目重发。

头像继续用已有杯子与小鸟素材，由真实气泡遮挡下半部；文字留在正常气泡内。
