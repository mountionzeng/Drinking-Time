# 编辑器真实按钮与后端验收

## 环境与范围

- 主仓 `main:3000`，`pnpm env:status` 确认唯一开发服务。
- 用户明确允许实际点击及必要生成费用。通过 Chrome UI 创建独立故事 1202「按钮验收 1003（虚构）」，材料为雨天修伞铺；未对原故事主动应用、丢弃编辑或停用分享。
- 本轮检查文章生成、编辑采用、图片生成/选图、段落定位、复制、下载和分享。未生成视频、录音或向他人发送内容；未部署公网或执行数据库迁移。

## 实际复现和修复

1. **文字历史被普通保存删掉**：真实生成失败记录在旧浏览器状态保存后消失。`mergeStaleStoryBody` 调用 `prepareStoryBody` 时遗漏权威 server body，后者把文字历史当成伪造字段删除。新增测试先失败后通过；合并现在传递原 server body，仍拒绝客户端伪造历史。
2. **第一篇新稿不能保存**：独立生成只写本地 buffer，发布区的 dirty 和保存动作却要求已有正式稿。新增 buffer 来源版本 ID，编辑与刷新保持来源；主按钮直接「采用文稿」，使用原 `textDrafts.adopt` 的所有权、修订冲突、标题和成品快照保护。首次生成、手工改文、点击采用实测通过；服务端采用内容与发布正文一致。
3. **两个文稿入口走不同管线**：删除空白发布区的重复初次生成按钮，保留聊天下方唯一生成入口和现有跨平台转换能力。
4. **模型失败原因被吞掉、等待无上限**：文稿只暴露安全的错误分类，保留不确定费用语义和完成时间；显式请求 low reasoning、90 秒期限，连接不确定时不暗中重放。提示词与原始供应商错误不输出给用户。
5. **提示词整理失败却留下虚假出图任务**：封面英文编译采用 low reasoning、45 秒期限；在真正提交图片之前失败时将任务标为 failed，明确「尚未提交出图」，不留下 pending。主配图区显示必要错误状态。持久任务回执遇到前端新 token 仍优先恢复，不覆盖已付费任务编号。
6. **新故事临时 ID 的无效 API 请求**：视觉编辑会话激活与成品查询只在持久化正数 storyId 上执行。
7. **系统图片分享能力判断**：只有浏览器能分享实际 PNG 文件时显示「分享图片」。本机 Chrome 支持，实际打开系统分享面板，显示 3 张图像 / 6.1 MB；未选择接收人，已关闭。

## 回归证据与限制

- 10 个定向测试文件共 150 项通过，包括生成失败分类、超时未知费用、禁止模型重放、已付费任务新 token 恢复、首稿采用入口、来源 ID 保存、旧状态合并保护。
- `pnpm check`、`pnpm build`、`git diff --check` 通过；`pnpm feature:validate` 校验 49 张功能卡通过。构建仍有既有大包提示。
- 所有 Vitest 持久化位于独立临时目录，没有使用真实业务文件作为测试夹具。
- 分享链接在 localhost 可创建/读取/停用；真实他人登录续写和公网交付仍待部署，不能用本机验收代替。部署缺口见 `2026-10-02-story-context-sharing.md`。
- 当前网络域名经过本机 fake-IP；无凭据 HTTPS 探测可达（约 2.3 / 4.7 秒），但真实模型连接有波动。未修改代理、密钥或替换供应商。绘图耗时主要仍在供应商，本轮没有承诺固定秒出图。
- 本轮未新增横版插图/底图付费轮次，也未测试视频/声音及真实接收账号的续写；复用已生成候选验证多图定位与导出。
