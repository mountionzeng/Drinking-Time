# 基于回忆续聊

用户确认新想法追加到同一故事，原回忆保留。原聊天点句、存档选卡、账号回忆展开时设置来源；底部角色打开回忆续聊，首页无来源仍沿用新故事。来源在离开该阅读页时清理，打开后的会话保持其来源。未发送/未同步时不能静默切换。

引用与新想法作为明确标注的用户消息经既有durable mobile turn追加，来源为文本引用（包含原话角色与ID），不是新的外键或可点击来源关系。助手旧回复明确标注非用户事实。只在发送时生成，不自动产生正文或视频、不修改原卡片。原聊天自动收录链继续产生新回忆，刷新故事记忆缓存。

聚焦续聊不展示先前所有聊天。收起保留草稿与阅读基线，按账号本地恢复，复用已有退出清理前缀；发送前失败恢复输入，已发失败沿用对话轮恢复。账号切换重置UI上下文。

验证：7文件52测试通过及pnpm check通过，覆盖同故事提交、引用角色、打开不推理、空提交结果恢复、账号恢复隔离、聊天与故事回归。主仓3000点原话后底部入口变为接着这段回忆聊，引用和专用问候出现；填入验收草稿、收起重开逐字保留，随后清空。未发消息、未调用真实付费模型，生成质量及真实断网仍待验收。未部署。

限制：没有来源故事的独立卡片、来源故事已删除的卡片不能追加到不存在的故事；已删除故事会由现有服务归属校验阻止。引用目前作为正文保存在消息中，后续目录可能仍需要更精简的引用呈现。
