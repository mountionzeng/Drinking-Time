# 播放闪动与界面精简

## 修改

- 修复播放镜头与对话旧选区相互争抢。原先播放时钟每帧更新 selectedShotNo，而 EditingNleWorkspace 的选区跟随 effect 依赖 selectedShotNo，把它重新设回聊天镜头，造成高亮反复变化和 Maximum update depth exceeded。现在每次显式选择只跟随一次；更新素材数组、继续播放和暂停不重复消费旧选区。新点击同一镜头仍生效，尚未加载的新镜头等待加载，外故事和时间范围不误导航。
- 整片总时长从10px改为20px、红色加粗，仍显示原完整片长。
- 按用户要求删除“一键生成·约30秒”按钮及专用无入口的批量执行状态/handler；逐镜与对话生成保持。
- 退出或收起镜头历史后，恢复完整对话并滚动到底部；打开历史仍从本镜记录顶部开始。
