# 场镜 / 章节层级与分镜概览

日期：2026-11-08（Asia/Shanghai）。本地主仓 3000 验收，未提交或部署。

## 已完成

1. 场 / 镜头和章 / 节使用一致的父子规则。转换新标题时退出前一个同级子树，折叠组之后创建的下级标题归入前面的场或章。禁止通过移动或转换制造同级套同级；读取旧稿时不全局改写旧结构。
2. 上下键以同级完整子树排序，拖到场或章的边缘时仍归入该单位。图片、台词、音乐、描述及稳定 ID 一起移动，序号仍按新归属推导，不覆盖用户标题。缩进统一为 28 设计像素，缩放和图片坐标使用同一常量。
3. 顶部显示场数 / 镜头数。场显示所含镜头及图片数，镜头显示字数、台词句数、图片数、音乐秒数；统计随真实子树变化，折叠不影响统计，不另存内容副本。
4. 展开的镜头标题下直接预览参考图，原图模块、原顺序、两栏排版仍保留。新生成分镜稿默认展开场、收起镜头详细内容，复用现有展开三角。

## 统计口径

- 字数：正文 / 说明 / 台词的文字和数字字符，不计标题、标点、空白和媒体引用标记。
- 台词：仅统计明确标记为台词的非空内容，按换行和句末标点分句。
- 图片：当前镜头子树中真实图片模块数量，不把预览重复计数。
- 音乐：只统计实际音乐模块，浏览器读取音频 metadata 的真实时长并相加。有声书独立计数；音乐建议、预计镜头时长及视频时间轴中的音乐不冒充书内音乐。元数据尚不可读时明确显示时长待读取。
