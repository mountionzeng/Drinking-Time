# 模块跨页移动

## 入口与行为

- 在图像 → 排版，右键文字或图片模块，选择「移到其他页」→目标页。支持 Shift+F10 / 菜单键、方向键及 Enter；输入文字时仍保留原生编辑菜单。
- 目标列表显示页码和页面名称，当前页禁用；「移到新一页」在末尾新建页面，九页时禁用。单页作品也可移到新页。
- 移动整块，不复制；保留文字、提亮、半透明底色、图片源、裁切、坐标和尺寸。目标模块标记为自由摆放，后续普通增改文字不会自动挪走它。
- 其他模块不重排，源页变空也保留。移动后显示目标页并选中模块；一次撤销/重做同时恢复两页，并跟随仍选中的模块。
- 保存键、草稿格式与共享绘制器不变，不涉及原文写回、素材修改或生成费用。超过目标容量、重复 ID 或失效页时不改变原文档。
- 当前为菜单移页，未加入拖到缩略图的跨页手势。
