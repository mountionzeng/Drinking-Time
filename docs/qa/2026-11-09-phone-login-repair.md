# 手机号验证码成功后建号失败

## 根因和证据

用户报告正式站短信收到但不能登录，随后截图显示发送限流与74270秒倒计时。通过现有阿里云运维通道只读核对：该号码挑战 attemptCount=1 且 consumedAt 非空，手机号身份数量0；生产 users.openId 最大64字符，PM2错误日志有4次该列Data too long。未读取验证码或摘要、未打印密钥，未写生产数据。

旧生成规则 phone: + SHA256 hex 为70字符。验证码消费成功后 upsertUser 插入失败，重试原验证码不可用，重发触达每日两次限制。修复为 phone: + 完整SHA256 base64url，共49字符。现有身份仍优先读取，不合并/迁移账号，不放宽验证码限制。
