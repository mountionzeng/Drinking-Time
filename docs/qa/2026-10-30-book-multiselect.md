# 书页多模块选择（本地）

- 空白处鼠标拖动框选，Shift 点选增减；点击空白或 Escape 清除。
- 选中模块显示细边线；沿用原把手和角标，不增加移动按钮。拖把手整组排序，标题内落点沿用原逻辑。
- 标题选择包含隐藏子块；按文档顺序移动、子树不重复、不允许放到自身内部。
- 批量缩放沿用字号 ½–2 倍限制，图片保持裁切、原图及视频引用；图片几何同步缩放，页内边界限制整组比例。流式排布避免文字重叠。
- 只在松手时提交一次至现有 onCommit，沿用自动保存、CAS、格式保存及撤销。取消、Escape 或手势期间块数据变化时不覆盖最新稿。
