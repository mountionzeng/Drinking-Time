# 手机小忆上下文与内容操作（2026-10-13）

## 本次行为
- 故事详情随阶段提供回忆、所选文字版本/当前正文、视频素材上下文；点原聊天句子或存档卡片优先使用该段。全部文字/视频列表展开项目时也带入对应来源，退出清理。
- 视频上下文为字幕、制作说明、素材地址，明确不表示看过视频画面。无内容时明确说明为空；首页保持独立聊天。打开不创建故事、不调用模型。
- 小忆底部三个轻量入口：导入本地文件、标记为记忆、加入某段文字。预览面板仅点击后打开，操作中锁定来源和收起，避免切错故事。
- 图片/视频调用 creationAgent.importStoryMaterial，校验尺寸和显式视频镜头，处理 status:error；刷新素材缓存。TXT/MD 合入输入草稿（UTF-8，100KB/合并后12000字以内），不自动发送。图片30MB，视频200MB；媒体需要选择已有故事，视频需已有镜头。
- 记忆调用 memoryWarehouse.save，保留助手/用户/记事来源，来源故事自动关联，账号级空聊天允许 sourceStoryId:null。保存请求带幂等 UUID，失败不清输入。
- 加入文字可选当前正文或独立版本。当前正文追加末尾，通过 publishingDraft.saveBody 的版本/平台/bodyRevision CAS 保存；保留已有段落。独立版本调用 textDrafts.revise 另存一版，不自动采用、不改原稿。先选内容与目标并可查看合并预览；冲突保留内容，可重新读取目标。

## 限制
- 不做图片OCR或视频画面分析；不支持PDF/DOCX解析。
- 当前正文使用已有正文保存接口，追加原有段落，不承诺额外生成独立文字历史版本。
- 媒体导入沿用非幂等接口，网络中断后应先检查素材库；未验收真机200MB上传与软件键盘。
- 来源为消息中的标注引用，尚无结构化回溯链接。账号无故事时可导入文本、保存独立记忆；导入图片/视频需先建立故事。
