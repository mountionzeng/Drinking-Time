## 用户操作

1. 打开 http://localhost:3001/editing 的 launch video，进入「剪辑与预览」。点击视频或视觉时间线。
2. ← / → 逐帧移动；↑ 暂停并将当前帧存入仓库、带入对话；↓ 取消当前引用。输入框内方向键仍用于编辑文字。修饰键既有剪辑指令保留。
3. 对话提示「已引用这一帧，直接说想怎么改。」只显示小图标和时间。点击图标展开原帧、镜头、Take、剪辑修订。
4. 可以直接输入「只让色彩更细腻，其余不变」；也可不按上键，暂停后输入「这一帧……」。后者从开始输入或开始录音时冻结位置。
5. 显示原帧和 MJ 报价，回复「确认」才调用模型，回复「取消」不生成。候选后续仍需明确采用。
