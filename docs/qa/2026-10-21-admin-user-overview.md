## 实现与口径

- `/admin/users` 首屏展示已验证注册账号、已确认外部账号、待确认、近七天新增/活跃、注册账号累计消耗。
- 同一个 userId 绑定多个已验证身份只计一次；包括无邮箱的手机/微信账号。访客和无验证身份的历史账号单列。账号数不等于自然人数。
- “自己的账号／测试账号／外部用户／待确认”是独立管理员分类；未知默认待确认，不推断外部身份。`admin_user_labels` 保存分类、操作者和时间，不改变角色与余额。
- 访问仅统计页面当前域名；七天为滚动168小时，排除未来时间。注册日期使用账号建档时间。没有访问记录不等于从未使用，最近登录独立展示。
- 算力来自现有 credit_accounts / credit_ledger_entries；注册账号和外部账号消耗分开，不冒充全供应商实收。
- 原邮箱访问/图片视频生成详情折叠保留，原算力页和邀请页保留。手机“我的”仅管理员显示用户管理入口。
- 管理员 API 同时支持查询和分类，客户端不是授权边界；显式安全投影排除凭据、OpenID、身份 subject、故事及素材内容。
