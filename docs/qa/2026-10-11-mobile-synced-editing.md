# 手机故事首页恢复与同步编辑

用户明确：恢复此前故事首页；点记忆/文字稿进入详情；文字与记忆可编辑，视频先查看。

## 结果

- 首页恢复“正在继续”卡片与“以前的故事”列表。卡片的两个入口为查看记忆、查看文字稿；底部当前“故事”按钮也能返回首页。
- 当前记忆按故事及其文字稿来源卡片读取，50条分页，先列表、再单条阅读、再按需打开编辑。
- 记忆修订由 `memoryWarehouse.revise` 原子写入共用仓储：新内容为用户记事，旧卡保留在归档，已有文章来源快照和原聊天不变。已有桌面仓库读取可见。
- 独立文字版本由 `textDrafts.revise` 保存手动新版本，保留旧稿/来源和原发布正文，不调用模型、不自动采用。已有桌面文字历史读取可见。
- 当前发布正文继续使用既有body-only CAS保存；重进详情和窗口重新聚焦读取权威正文，未保存输入由原状态机保护。
- 编辑表单仅在明确点击后出现，失败保留输入；本机恢复按账号/故事隔离，切账号与退出会清理。

## 验证

- `pnpm exec vitest run client/src/features/mobileWorkspace server/routers.memoryWarehouse.test.ts server/services/textDraftHistory.test.ts server/services/chatMemoryWarehouse.test.ts server/repositories/boundaries.test.ts`
- 结果：14个测试文件、111条用例全部通过。
- 后端隔离数据用例验证：手动修改读回同一共享历史/仓库；不同账号拒绝；重复请求不新增版本/卡片；并发修改只接受一次；原文归档、旧文字与来源快照保留；聊天重收录不复活归档源；手动修订不调用模型。
- 手机现有保存、恢复、归属与切故事保护回归通过。新增当前导航按钮再次点击回首页回归。
- `pnpm check` 通过；`pnpm feature:validate` 通过，53张功能卡有效；`git diff --check` 通过。
- 主仓3000内置浏览器：恢复首页→查看记忆→单条阅读→编辑；临时输入取消先提示，明确放弃后仍显示原文；底部故事回首页→查看文字稿→历史版本编辑。
- 320×640编辑弹窗边界 x=8–312、y=32–608，无横向溢出，标题、正文与保存按钮均可见。390px首页/编辑器检查通过。
- 截图：`2026-10-11-mobile-story-home-restored.jpg`、`2026-10-11-mobile-memory-editor.jpg`。

## 限制

同步是显式保存后共用数据，非逐字实时协作。浏览器没有保存测试修订到用户故事；持久保存、重试和并发通过隔离测试核验。记忆打开会沿用已有无模型聊天镜像补齐。未调用付费生成、未上线；MySQL新修订事务、真实双设备公网与真机软件键盘仍待专项验收。视频按用户明确选择维持查看。
