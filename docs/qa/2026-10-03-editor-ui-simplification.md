# 编辑页面入口与文案精简

日期：2026-10-03。用户明确要求清理重复按钮和大段解释，按钮名称应直接说明用途。

## 范围与取舍

- 核查文字工作区、聊天下方文稿入口、整套配图、封面编辑、逐页画册和分享发起/接收页面。
- 分享仅保留文稿顶部一个入口；正文存在时使用正文状态栏的「文字历史」，无正文时仍保留顶部历史入口。
- 封面编辑统一放在配图区，移除文稿顶部导航、底部按钮和生成小窗中的重复入口。逐页画册保留自己的封面入口及返回正文操作。
- 删除“先选一张，再修改”的无操作占位按钮；画册当前页标签改为普通文本，避免看起来可点击却无动作。
- 文稿方向使用「自我梳理 / 分享经历 / 记录片段 / 虚构故事」，确认区只保留「生成文稿」。方向可再次点击取消，未选方向沿用已有默认生成路径。
- 按钮明确命名「分享图片」「分享链接」「编辑封面」「设为封面」「下载原封面」，设置折叠为「排版设置」和「逐页编辑画册」。
- 删除 AI 宣言、自动出图说明、重复质检汇总、预览与下载说明、重复的生成进度句；图片自身的风险标签保留。
- 保留价格和显式付费确认、失败/缺图/失效锚点、未保存状态、聊天分享开关、持链阅读及可转发范围、本机链接限制和撤销后的副本保留说明。未触碰生成、保存、撤销或账号权限接口。
