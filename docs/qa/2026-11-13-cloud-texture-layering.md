# 云数量、纹理重复度与森林过绿纠正

2026-11-13；主仓3000，story1217 / 第03镜。功能卡 chat-keyframe-region-review 保持 partial。未提交、推送或部署。

## 需求与实现

用户反馈候选2103的树过绿、层次不足，云可更多但纹理不要重复，并要求写进程序。

- cloudArtDirection 持久保存 quantity(preserve/slightly_more) 与 textureRepetition(preserve/reduce)，两者独立。后续同图短句保留要求，明确数量不变/纹理原样可撤回；新报价指纹绑定参数，旧回执保持兼容。
- 生成提示词将少量增云与纹理变化分别编译。减少克隆云团、相同小球与平铺纹理，变化轮廓、尺寸、疏密及细颗粒分组，保持原有点彩媒介、主要云中心及空间留白。
- 森林 reduce_green_flatness 独立于旧蓝树转绿/继承配色。只降低选中树冠绿色色域的色度，保留Lab明度、蓝色阴影、棕色树干与局部颜色差异，向内柔边；不宣称重建了空间层次。
- 对候选图再次定位，前端原来仅检查原始frames，忽略sourceImages/candidate/报价底图，导致误入普通改图报价。补完整范围会话归属检查。
- 森林tone纠正走完整SAM2树对象识别，避免粗分割只检出一小块就跳过细化。
- 云完整轮廓在本图的SAM评分低，单个重复小球评分高。诊断59个提示点后采用有边界的多点一致性补充：至少3个相隔短边1/12的点，蒙版IoU>=.9，云语义覆盖>=.9，保护重合<=.01，面积<=全图25%。仍然先预览，不自动确认。保留原高置信度路径，拒绝单点/背景/无语义支持扩张。
- 确认范围时逐句检查已保存的云外观要求，后续“重新定位”不能吞掉先前的增云和去重复要求。
