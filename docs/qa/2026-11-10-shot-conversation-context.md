# 镜头对话、历史与图片入口

## 本轮结果

- 点击右侧镜头标题，自动打开该镜头的对话、修改历史和图片；输入区保留一个可收起的小框，历史在对话滚动区，不再挤占输入框。
- 点击对话内镜头引用或小框，可打开对应镜头。清除选择回到全部对话。
- 无需先点镜头，可直接输入“第二个镜头…”或“shot 2…”，解析明确镜号并持久记录稳定镜头身份；不存在或多镜号不猜测。
- “查看第二个镜头的修改记录”在本地直接打开，不调用模型、不新增对话记录。
- 点击历史图片只选择上下文，不采用、不替换主图。图片相关提问在空闲及排队时都走对话，不直接作为改图执行。
- 新两图结果保存服务端镜头关联记录，包含镜头、图片ID、原话、时间、用户ID；刷新后可由历史查询恢复。此记录不改变图片采用状态或时间线。故事权限、生成前镜头存在检查、CAS、幂等和普通保存保护已覆盖。
- 旧明确镜号对话以“旧对话中的镜号提及”展示；稳定身份记录优先。旧无归属图片收进折叠区，不伪造镜头归属。
- 已结束图片任务收成按镜头去重的小框，任务恢复查询仍保留。修复历史区域与消息区域重复 React key 导致的残留。
