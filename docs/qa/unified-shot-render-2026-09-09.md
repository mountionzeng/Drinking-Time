# 统一镜头渲染入口 · 2026-09-09

用户授权将“渲染4张”和“参考素材出1张”合并，并简化底层实现。工作在独立 `codex/unified-shot-render` worktree 完成，不启动第二服务，不复制业务数据。

## 最终行为

- 默认渲染1张，按钮中可填1–8；四张报价为约¥5.96（每张约¥1.49），总价确认后逐张调用已验证的GPT单帧通道。
- 每个缩略图对应明确的参考ID；可增加、替换、移除或清空。整场默认宠物先显示出来，用户编辑后完整列表取代自动继承。清空不删除仓库资产。
- 服务端重新解析图片和资产归属，不相信客户端URL。空列表清掉旧图、封面、角色等隐式参考；缺失镜头、素材或费用确认阻止提交。
- 张数和选择按Story+stableShotId保存在localStorage；新的图片保留为候选，不覆盖当前采用图。
- 逐张失败即停、不自动重试；离开当前故事后不再提交后续任务。已经提交的任务可能仍在供应商运行。
- 共享schema/报价/串行执行器，复用原有单帧请求和持久化路径。原精确编辑、遮罩、视频流程保留。
