# 手机内容汇总与故事阶段动效

用户明确要求以回忆、文字、视频替换首页说明，聚合账号内容；故事内仍为单故事阶段，左右滑动使用六种简短过渡。

- 回忆复用账号 memoryWarehouse.list，每页50条；不限定当前故事。文字按故事展示当前正文及历史版本；视频按故事展示既有素材。文字/视频每页5个故事，所有故事可翻页访问，不对全部故事同时发起请求。
- 汇总只读；进入原故事继续编辑，保留已有未保存正文的切换确认。旧聊天尚未收录的条目需沿用原有仓库同步；账号汇总不自动执行补录或生成。归档记忆不显示。
- 六种阶段入场：拾光轻翻页、金弹性滑入、木轻摆、水柔和侧移、火向上浮起、土柔和落定，0.18至0.24秒；尊重减少动态效果。沿用既有滑动阈值、编辑保护、选择文字与视频控件排除及边缘不循环。
- pnpm check通过；MobileContentLibrary、mobileStageMotion、MobileStoryWorkspace、MobileWorkspace、mobileStageSwipe、useMobileStageSwipe共6文件47测试通过。
- 主仓3000实际374×774：回忆列表、文字版本展开、当前正文、下一页、视频空态、详情文字/视频切换及fire主题接线通过。没有发送消息、生成内容、采用版本或修改业务正文。视频样本为空，实际播放与真机手势/低性能流畅性尚未验收。
