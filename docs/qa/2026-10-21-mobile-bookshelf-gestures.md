# 手机书架长按与拖动

用户授权以直接操作书本替换手机版“整理书架”；电脑版保留原整理入口，数据继续共用。

## 行为与边界

- 短按阅读；普通手指滑动仍滚动页面或横向书架。
- 持续按住500毫秒后出现提起提示。此后移动超过10px进入拖动，松手按落点保存；未拖动就松手打开单本摆放与概览。
- 拖到“加一层书架”时，建层和放书在一次账号锁/事务内提交；拖到已有层可调整位置，边缘自动滚动。无效落点、触摸取消、切换窗口或Escape取消操作。
- 拖动保留这本书当前摆放姿态；松手拦截随后点击，避免误阅读或误新建空层。搜索中提示先清空搜索再拖动。
- 默认列表继续最近编辑优先。用户首次手动调整默认层时，将当前完整未分层顺序保存成“我的故事”层，再插入到指定位置；之后使用手动顺序。没有数据库迁移、没有新数据表。
- 手机每层的“···”保留改名、上下移动和移除层；移除层仍保留故事。单本原省略号入口保留，便于不使用手势的用户操作。

## 验证

- 路由与手机汇总27项通过，覆盖原子新建并放书、默认层手动顺序、跨层插入、保留姿态、未读不变、他人故事与错误落点拒绝、过期版本冲突不产生空层。
- 主仓3000运行浏览器CDP触摸事件：长按松手打开摆放，普通滑动与touchcancel无写操作，拖到新增层及跨层目标发出正确保存参数。书架接口使用虚构故事并拦截写请求，不修改用户书架；真实持久化由路由测试覆盖。
- 可复现脚本：`node scripts/verify-mobile-bookshelf-gestures.cjs`，依赖本机Playwright与Chrome。截图仅本地 `/tmp/dt-gesture-mobile.png`。

## 尚待验证

真实iOS/Android触摸手感、屏幕阅读器和正式双账号跨设备体验仍待验收。本轮未跑MySQL集成测试；沿用现有账号事务，没有数据库结构、环境变量、nginx或证书改动。

补充验证：TypeScript、独立提交归档生产构建、66卡校验通过；320px模拟触摸边缘自动横移、无效落点取消、松手不误阅读通过。拖动落点识别可穿过小忆浮层；验收时将起始书本滚到屏幕中央，避免手指先按在浮层上。

## 手机页面去冗余

用户追加截图授权：手机故事/人物页去掉回忆标题、眉题、记事工具与内部分栏，故事页再去掉搜索和数量说明，直接展示内容。电脑版保持原有界面。记事入口迁入仓库文字的“记事存档”，不删除原有能力。现有回归同步检查重复区域不存在、记事新入口存在。
