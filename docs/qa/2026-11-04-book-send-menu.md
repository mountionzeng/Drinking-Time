# 2026-11-04 书稿发送入口与分享图片修复

用户要求在书稿底部“把书做成视频”右侧增加“发送”菜单，找回已有发送能力；随后反馈分享只有文字、丢失文章插图。

## 原因与处理

- 原文字分享只接收文字快照，不包含书稿图片。新菜单的“分享文章”先沿用 ChapterWorkspace 的准备/保存流程，保存成功后取当前编辑器正文和当前故事标题，避免分享旧平台稿。保存失败、作用域切换或图片读取失败均阻止进入不完整预览。
- 有图片的书稿复用 ArtworkShareDialog/artworkShare：先读取全部插图并转为独立像素副本，再预览按正文顺序排列的文字和插图；确认后才创建链接。服务端继续解码重编码图片，保留原裁切、标题、加粗和 LaTeX 显示，不公开原图访问地址。
- reading 仅保存文字、图片索引和裁切。严格校验索引、字段、裁切和文字总量；正文参与原幂等指纹，已创建链接不能以相同令牌换稿。默认只读，改写/另建故事仍需显式授权；旧成品图片分享兼容。
- 无图片书稿继续原 StoryContextShareDialog；纯图片书稿也可预览分享。沿用最多 9 张不同图片、输入合计 8 MiB 限制，重复图片只准备一次，正文位置保留；超限明确报错，不截断文章。
- 找回的章节投递、收件箱、发回修改稿在文字模式收进“发送”菜单，仍受原 chapterDelivery 开关和来源约束控制；图片模式原入口保留。本机未启用该开关，本轮不擅自开启。
