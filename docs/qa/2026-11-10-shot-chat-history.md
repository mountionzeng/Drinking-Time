# 镜头对话修改与历史 · 2026-11-10

用户要求点击镜头直接在原对话修改，并能看到这个镜头此前改过什么；沿用极简界面，不另建修改按钮。

## 本轮结果

- 分镜表行、剪辑视图媒体区（含空白镜头）、剪辑线选中均展开原对话。显示镜号、当前图像、内容与历史；仍使用原输入框。
- 历史按 storyId + stableShotId 汇总字段版本、剪辑快照、已绑定镜头的对话要求、图像修订和视频 Take。记录按时间排列，可展开前后内容与媒体；旧快照不冒充原始修改时刻，旧图片成员关系不冒充采用事件。
- 普通自动保存原先会清掉 storyboardFieldVersions；现纳入服务端权威字段保护，专用写入/恢复/生成声音/分镜确认仍可写合法历史。
- 新字段修订记录实际用户 ID；旧记录没有编辑者时明确显示未记录。不会为旧记录补造作者。
- 排队消息冻结当时镜头/选图，切镜后仍按原目标提交；对话完成记录持久保留选区引用。
- 无图片镜头以整镜对话上下文提交，不伪装成文本选区；表格输入框保留光标，选镜展开不抢焦点。
- 新界面有中/英/法词典；视频历史候选可预览并按提示用文字采用。
