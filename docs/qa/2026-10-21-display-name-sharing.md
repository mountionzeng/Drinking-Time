# 自选名字与文章分享署名

## 本轮范围

手机“我”页直接说明“名字由你自己定。分享故事时，对方会看到这个名字”，提供昵称／笔名修改入口。已有账号名保留；默认 Guest 展示为“给自己起个名字”。保存到原账号 users.name，两端读取同一字段，不新增身份、迁移或环境配置。

文字分享预览与新建链接使用服务端账号名生成署名快照，接收页面在正文标题下展示。改名后新分享使用新名，旧链接保留原快照；旧数据没有署名则不补造。图文分享和分享回来本来就使用同一账号名，保持原权限及快照逻辑。

## 人物关系梳理

- 账号身份决定故事归属、权限和共创人物标识；昵称仅用于展示，同名不合并、改名不重建关系。
- 邀请／共同创作来自实际接受分享和回传记录。旧链接不能推断未接受的收件人。
- 私有亲友关系仍由用户维护，不因分享给某人就推断亲属关系。
- 本轮先补个人名字及文字署名，不重置已有人物记录，也不追溯修改历史贡献署名。
- 对外新字段只有 author.name，不含贡献者 userId、token 或 requestHash。
