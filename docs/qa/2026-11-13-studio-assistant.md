# 界面感知与对话操作验收

实现位于 `codex/chat-ui-actions`，基于本地 main `6d208cf7`，与故事邮箱共用真实服务。当前尚未合入主仓或发布；用户明确要求等待云层编辑会话完成后再合入。

## 本轮行为

- 每轮聊天固定当前故事、页面、邮箱联系人、选区摘要及保存状态。书稿写作和普通聊天都能读到状态；此快照不是屏幕截图。
- 对话可打开页面、仓库和邮箱，列故事与联系人，读取作者署名修改记录。
- 发送/接收/停止联系的目标在对话内确认，无需操作按钮。服务端重新验证账号、故事、联系人、来稿归属和快照指纹；重复确认幂等。
- 未保存书稿和正在保存的时间线阻止发送；界面/账号/故事改变后旧确认与迟到导航失效。操作失败不再落入另一聊天代理执行。
- 邮箱在大屏侧边打开，聊天保留交互。纯界面指令不创建空故事；写作内容仍可正常形成故事。
