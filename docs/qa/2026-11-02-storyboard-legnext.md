# 分镜表 Legnext 图片渲染

根因：上一轮仅moduleTarget书稿转换切换供应商，分镜表generateForMobile未带该字段，仍走302冷却与过载。

修复：rerender增加一次请求UUID；服务端按镜头身份与所有者记录storyboardImageTasks；新分镜请求走Legnext V7 Fast，16:9，旧302/选图精修路径不改。恢复先取旧回执，不重复提示词整理或付费POST；四候选保留镜头关联、不自动采用。

参考图必须可供供应商读取，否则明确失败且不提交，不静默丢图；本地inline参考尚需公网托管，不能声称其闭环通过。

真实验收：本地3000，故事1214《蓝色纸船与灯塔》第01镜，点击生成4张→确认1.36算力，只有一次Legnext提交。供应商完成4张、consume80点（$0.08）。首轮等待超时，随后点击同镜头操作恢复原回执，未重复调用收费提示词或提交图片。候选1992–1995入库，四个PNG路由HTTP200；刷新后分镜表仍显示四张。未自动采用为当前主图，未生成第02镜或视频。

116项相关回归、tsc、feature:validate、diff检查通过。覆盖新请求路由不触达302、同请求重放、所有者隔离、未知结果阻止购买、恢复跳过提示词、并发恢复只入库一次。服务端采用CAS保护回执，恢复租约过期只允许GET，不放开新购买；首次提交轮询有总时间预算。

限制：恢复沿用原任务，界面目前仍会显示原报价确认框（服务端恢复不收费）；已受理与未知任务不会自动换供应商。带参考图路径保留输入、无法公网托管时明确拒绝，不以本次无参考成功冒充参考图验收。旧页不含shotImageRequestId仍走旧路径，需打开新版。
