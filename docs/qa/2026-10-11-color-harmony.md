## 实现与边界

- U1：可选 `colorDesign` 描述色环关系、整体／局部尺度、面积、纯度、明暗块面、边缘和媒介交接。旧六维配方仍可用，liked 仅保留共同方法，冲突进入收敛判断；版本和受控词库摘要可往返。
- U2：统一入口单次编译，保留字符串 API 与泛型 provider 返回值；同次编译可返回结构方法。首次聊天传当前 message，改图仍传当前 intent；实际发送文本随现有图片记录保存，不用编译前内容冒充。图片记录没有独立 recipe 列，未为此增表；已有 ArtDirectionCandidate/配方版本保留可选结构，当前活动生成入口以保存的最终 prompt 为继承权威。
- U3：手动／语义风格卡以及同批 ready 匹配可消费方法，来源色板不自动复制。只扩展 art-curation，普通照片结果不接收新结构。未修改 active 卡、真实目录、99 张原图、权利或分析状态。
- U4：`【配色关系】` 可全局继承，局部明暗位置与当前局部用户要求独立成段；画册作者模式不重新推断。
- 原有语义概念打分未改；配色否定、引号和条件语句处理独立实现，避免改变已有卡片命中。识别仍是有限词汇规则，未知表述保留原指令，不宣称完整语言理解。
- 配色字段不含色名、姓名、路径、源图情节或精确百分比；无固定“难过＝蓝色”。未知媒介不自动指定叠色技法。不开新 UI、不增加每张图片的模型调用。
