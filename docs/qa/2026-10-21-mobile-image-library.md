# 手机账号图库与故事图片页验收

日期：2026-10-21。主仓 `localhost:3000`；本轮不调用付费生成。

## 用户入口

- 故事首页新增「图片」：分页读取当前账号的全部服务器生成图片，包含旧故事和历史候选，轻点放大，点击故事名进入该故事的图片阶段。
- 故事内为「回忆／文字／图片／视频」四个阶段。「图片」只展示该故事资料，复用电脑端的图库、生成、排版与分享。
- 文字页「把文字变成画面」卡片通向图片制作；历史稿仍使用所选来源，不自动采用。未保存正文必须先处理。
- 图文制作依次提供「图库／排版／成品」。无正文也能浏览已有图片；新生成仍要求已保存正文及显式费用确认。
- 无故事账号的欢迎页也有「查看全部图片」入口。

## 数据与约束

- `storyAgent.accountImages` 为受保护的共用只读接口，不建立手机数据副本。按 ID 倒序，每页24张，以独占游标读取后续页，不限制故事数量。
- 同时校验故事与图片归属；无图片 userId 的旧记录只有故事归属明确才展示。无 storyId 的图片必须有当前账号归属。删除或无法确认归属的故事记录不暴露。
- 仅返回图片 ID、故事 ID/标题、图片 URL 和创建时间，不返回 userId、prompt、token、requestHash 等内部字段。
- 故事图库合并同故事候选与本机图片；按账号和故事读取跨版本上传，避免同号账号前缀误配为另一个故事。
- 没有迁移、环境变量、nginx、证书改动。

## 验证证据

- 定向29文件、251项通过：手机工作区、图片生成保护、四阶段手势、故事图片合并、账号权限/分页及路由登录校验。
- 权限用例包含跨账号、图片/故事归属冲突、legacy 空 userId、孤立故事、未分配图片、私密字段裁剪；60个故事跨页且插入新图后不重复、不漏掉原有结果。
- TypeScript、生产构建通过；既有大包体积提示仍在。
- 浏览器390px：账号首屏24张，点图放大；从「再写一版更轻松的文字」进入其图片阶段，显示18张既有素材；费用确认展示4张／0.68算力，取消，未提交生成。
- 浏览器320px：账号及故事图库宽度均为320，无横向溢出；文字快捷卡片、四阶段和图库导航可见。电脑 `/editing` 图像工作区继续显示故事图库与排版入口。
- 自动测试使用隔离持久化目录；浏览器仅阅读和界面切换，没有修改业务正文或购买生成。

## Known gaps

- 本轮环境未配置 `TEST_MYSQL_DATABASE_URL`，MySQL集成测试未跑；不把此前发布的测试结果当成本次执行。
- 服务器生成记录不包括仅本机上传和浏览器导出的排版成品；本机上传仍在对应故事内，不能跨设备同步。
- 真机iOS/Android手势、长按保存及系统分享继承原验收缺口；本轮是桌面浏览器手机视口测试。
- 新付费生成没有实际提交；这里只验证报价确认及已有门禁回归。
- 朋友分享回来提醒的正式双账号验收由用户自行体验，未借本轮图库测试宣称完成。
