# 手机故事阶段与聊天阅读验收

日期：2026-10-11。入口：主仓 `http://localhost:3000/m`，未部署。

## 本次能力

- 故事列表点击当前故事或其他故事进入该故事工作区，不再重置到聊聊。
- 顶部仅一条“记忆 → 文字稿 → 视频”内容切换栏，不代表完成百分比。
- 记忆默认显示最新文字稿保留的记忆组合，也可查看本故事聊天；原话和助手整理分别标注。
- 文字稿默认整页阅读，历史版本放进一个选择器；当前发布正文仍可编辑、保存与处理冲突。没有发布正文时优先展示已有独立文字稿。
- 视频阶段只读取该故事的 `storyVideoAssets`，可播放已有可用素材，不含生成和时间线编辑。
- 聊聊改为全高消息区，取消覆盖正文的浮动聊天面板；保留头像及真实请求动画、发送、恢复、归档。余额和充值在“我”中仍可见。
- 聊天输入由当前故事工作区保存，切换底部页面不会清空未发送输入。

## 浏览器核验

Codex 内置浏览器，390×844 与320×640。

1. 当前虚构故事进入工作区：三段可切换，文字稿1显示完整正文，选择器展示实际历史。
2. 切换另一虚构故事“按钮验收 1003（虚构）”：仍在故事页，标题与查询范围随故事切换。
3. 两个虚构故事的视频素材接口均为空，显示诚实空态；真实视频播放未验收。
4. “我”中切换纳音/拾光：工作区继承主题，书本、小忆和个人纸卡保留。
5. 聊天输入填写临时文本，切到故事再回来，文本保留；随后清空，未发送。
6. 320px聊天页：文档宽度320，无横向溢出；消息区 y=57–480，输入区480–551，导航551–640，互不覆盖。
