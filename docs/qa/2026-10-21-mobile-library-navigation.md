# 手机故事、人物与仓库入口

用户授权首页这排入口仅保留“故事”“人”“仓库”，仓库内再分文字、图片和视频。

- 故事打开共用书架，人直接选中人物关系页；桌面仍默认故事页。
- 仓库默认文字，可切换图片/视频，切换时重置分页并清理旧续聊来源。进入所属故事时携带当前媒体阶段。
- 原记事工具、分页、账号归属保护、图片放大和视频浏览沿用，不新增数据副本或付费生成。
