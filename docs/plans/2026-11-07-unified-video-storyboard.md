# 同一视频的分镜稿与剪辑视图

用户要求：两个表镜头号一致、轻松切换、镜头可生成图片/视频/声音；剪辑条调整后下方信息随镜头变化，并自动升级视频版本。

## 决策与边界

- 已采用视频两视图都由 CreationEditor 的正式镜头、稳定身份和时间轴投影，逐镜表与横向剪辑表按同一排序。编号复用 displayShotCode，不用数组下标生成另一个号码。
- 待确认方案仍是候选，沿用聊天原入口；明确采用后才变为同一份当前视频。旧方案和成品版本不自动覆盖。
- 复用 StoryboardReviewBoard 的生成、参考图、费用确认、失败恢复与播放时钟，切视图不重建生成会话。每镜一个「生成」菜单选择图片/视频/声音。
- 结构剪辑成功后，在同一时间轴 CAS/事务中保留前后镜头与时间轴快照，沿用实际时间轴修订标识；拖动预览、无变化命令、失败不新增快照。它是视频剪辑修订，不自动冻结/替换既有成品组合版本。
- 镜头正文改写继续沿用现有字段版本；音频/字幕、图片视频引用及手动编辑都保留。历史快照可核对，整条时间轴历史恢复不在本次新增。

## 实施与验证

1. 当前视频逐镜视图：BookVideoWorkspace、EditingNleWorkspace、StoryboardPanel/ReviewBoard；新增 StoryboardManuscriptTable。验证同 stableShotId 的编号、顺序、选中与文字跨视图一致，移动/重叠/未放置投影遵守既有解析。
2. 原生成流程接入逐镜菜单；验证选对镜头且选择菜单只进入既有报价确认，保留参考和旁白正文。切换不卸载原生成状态。
3. 共享修订快照 codec 与 timelines 可选记录；visual persistence/原时间轴路由启用。验证 CAS 冲突/持久失败无部分版本、幂等重放无重复、原图/字幕/音轨不丢、快照不递归增长。VideoVersionHistory 展示自动修订。
4. 针对性回归、类型与账本校验，主仓3000只读/可撤销界面验证。记录截图和剩余边界，不对真实故事发起付费生成。
