用户已确认：同一本书独立维护章/节文字稿与场/镜分镜稿；互转按用途、受众、发布平台改编而非逐句搬运。转换预览确认后才采用。日常自动保存不增加作品版本号，正式保存/采用递增各自编号，记录时间、发起人、编辑/确认人、AI参与、修改摘要与来源。恢复历史另建新版本。视频来源固定到具体分镜版本和素材/时间轴快照，书稿更新提示但不改旧视频；新视频先确认方案与复用/补制，已有费用确认保留。

## 实现单元

1. 为既有章节增加稿件类型标记，沿用原编辑器/素材/账号边界；作品快照存入 story body，与稿件更新使用同一事务。未标记旧章保持兼容，初始类型由结构推断并展示。
2. 版本保存、历史读取/恢复、转换草稿和采用接口，服务端身份署名与并发修订检查。模型只在用户请求转换时执行，原稿和媒体保留；转换草稿可编辑且持久恢复。
3. 书页文字/分镜切换、版本详情、自然语言用途输入与转换预览。沿用绿色强调色、轻量按钮、原有编辑器。
4. 视频从已确认分镜版本规划，记录来源/作者/时间/意图；成片保存与导出记录连接既有视频版本管理，保留旧快照和失败状态。
5. 验证账号隔离、并发冲突、幂等、持久失败回滚、源变更拒绝、两种转换的媒体归属和版本恢复；类型/账本/草稿回归。工作树不运行服务、不写业务数据；合并需主仓独占。

## 边界

不改供应商、算力超时释放、部署或执行真实付费生成。旧数据不伪造历史作者或确认时间；模型生成质量与生产MySQL/真机验证据实列出。保留所有已有功能和用户原文/历史，转换改写仅作用于新目标草稿。
