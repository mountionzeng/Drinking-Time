# 可复用的分镜稿与图片继承

用户要求：其他故事也能使用本次整理流程，沿用现有入口，保留书内图片及前版视频画面。

- [x] 核对真实稿件：原四张图片仍在，第一、三场被折叠；旧版视频的稳定镜头身份需要跨格式继承。
- [x] 在现有视频对话提供“先整理为分镜稿”选项；原模块按完整、连续的组归入场/镜头，保留原文和媒体，原稿可从版本恢复。
- [x] 整理通过所有章节版本校验后原子保存；有并发编辑就停止，不覆盖草稿；已是分镜稿重复进入不再添加标题。
- [x] 用明确来源和一对一匹配继承稳定镜头身份、已生成媒体与人工参数，参考图片跟随当前书稿，不复活已删选项。
- [x] 不同故事模拟、重复操作、并发冲突、错配保护、跨发布版本继承及真实图片页面通过；证据见 `docs/qa/2026-11-06-reusable-book-storyboard.md`。

边界：不自动购买图片/视频/配音，不部署。配音会话的修改保持独立。旧稿不会被当作仓库全量选图授权。
