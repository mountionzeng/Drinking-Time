# 版本管理说明

一个成品版本由三部分组成：文字、图像和视频。

| 成品版本 | 文字 | 图像 | 视频 | 修改目的 |
| --- | --- | --- | --- | --- |
| V1 | Text V2 | Image V1 | Video V1 | 第一版完整成片 |
| V2 | Text V3 | Image V1 | Video V1 | 缩短开场 |

## 什么时候会更新版本

只有你在“正文”里填写修改目的，并点击下面三个按钮之一，版本才会更新：

- **保存文字新版**：记录当前文字，图像和视频保持上一版。
- **保存图像新版**：记录当前采用的图像，文字和视频保持上一版。
- **保存视频新版**：记录当前使用的视频，文字和图像保持上一版。

普通编辑、保存正文、生成候选、采用素材或生成 Take，都不会自动创建成品版本。

## 怎样完成一个版本

1. 写一句修改目的，例如“缩短开场”。
2. 点击本次真正更新的层：文字、图像或视频。
3. 如果还改了另一层，继续点击对应的保存按钮。
4. 确认表格无误后，点击 **完成版本**。

完成后才会得到稳定的 **V1、V2、V3**。已完成的版本不会被改写。

如果这次修改不要了，点击 **放弃**。它只删除正在整理的这一行，不会删除文字、图片或视频素材。

## 第一版为什么会同时出现三层

第一次保存时，系统会把当前成品作为 V1 的起点，所以会同时记录现有文字、图像和视频。以后创建 V2、V3 时，点击哪一层，就只替换哪一层。

记住一句话：**先修改内容，需要留档时再明确保存对应层，全部确认后再完成版本。**
