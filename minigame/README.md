# DK 小游戏迁移

用户已明确选择小游戏运行时。入口为 src/game.ts，使用 Canvas 和微信键盘，复用 miniprogram/src 的纯业务状态层。当前全部为 mock，不能称为手机版完整还原。

构建：`node minigame/scripts/build.mjs`。运行入口测试：`node minigame/scripts/smoke.mjs`。从仓库根目录执行；脚本通过 Git 定位主仓依赖，不依赖硬编码本机路径。开发者工具导入 minigame/。

已实现演示正文读取、键盘编辑、保存调用、聊天改稿/发送、前后台正文草稿保存、按故事隔离的内存聊天草稿、纵向滑动阅读、故事切换脏稿确认、复制两份冲突文本和未知轮次查询入口。长聊天逐行换行并按视口展示。尚未验证真机键盘、安全区、触摸流畅度；未完成三档面板、完整冲突裁决、聊天草稿跨启动恢复、正式认证和真实 API。当前工程仅用于开发，不能提交为功能完整版本。

后端账号适配需与已有认证工作区协调，共用原服务端身份与数据库，不向 Canvas 客户端放入 AppSecret。
